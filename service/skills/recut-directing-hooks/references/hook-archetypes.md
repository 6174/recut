# 钩子原型深化

> 来源注记：本文件裁剪改写自 vyralcontent/content-skills（MIT），原文件 `skills/viral-hooks/references/hook-archetypes.md` 与 `skills/viral-short-form/references/hooks.md`，搬运日期 2026-08-29。

## 六大基座原型（Kallaway）

1. **预言家**：“这类东西即将改变某群人做某事的方式。” 敢于下近未来断言，需配真实演示；无演示则像空话。
2. **实验家**：“我用 X 时间做了 Y，只为验证 Z。” 可见投入即信用，适合测评、挑战、并列对比。
3. **授业者**：“某人用反直觉方法拿到某结果。” 给出具体结果与具名方法，轻度新奇。
4. **魔术师**：“看这个，它其实是…” 视觉扛起钩子，口播只作指针；画面不够惊奇时不选用。
5. **调查员**：“我在熟悉之地发现被忽略的东西，它能…” 基线稳、命中率高、方差低。
6. **逆行者**：“人人都以为 X 是因为 Y，错，真相是…” 峰值最高、方差也最高；正片必须能自证，否则信任崩塌。

经验：在同一批稿中同时放“逆行者 + 调查员”，既有冲高可能也有稳命中基线。

## 其余框架的要点搬运

- **MrBeast 承诺一致**：标题、首帧、首句三者互为兑现；首句回响标题的承诺，首帧回响封面的承诺。短视频中即“三层一致”。
- **Hormozi 钩子-留存-奖励**：钩子在 3 秒内给代价或结果，留存段用具体证据填满，结尾给可带走的可用物；其标题句式“如何达成某结果且无需某痛苦”可直接作钩子母题。
- **Brunson / Kern 钩子-故事-诉求**：钩子打断、故事搭桥、诉求收口；面向陌生观众时把诉求软化为“收藏/评论”而非“购买”。
- **Koe APAG 注意力三问**：是否与观众日常相关、是否有可感知的收益或可避免的代价、是否匹配观众当下的认知水平；三问任一为否则钩子自说自话。
- **Welsh 三行钩子**：信息流中仅首 2–3 行可见，三行内完成“敌人—英雄—加速器—悬念提问”的节奏；落在短视频即为屏上文字的断行节奏。
- **Bush 大数字与扩写**：用奇数或精确数替代整数（“47 支口红”胜过“50 支”）；同一主张可沿 13 个向量扩写——技巧、数据、步骤、故事、引言、收益、教训、原因、错误、案例、提问、资源、框架，卡壳时换向量重写。
- **Galloway 点按即播放**：首帧构成为“刚被暂停的动作中段”，让人产生点开看完的本能；前 3 秒决定分发分水岭，标题与封面卖点击，首 30 秒卖观看。

## 选型速查

- 有强视觉结果 → 魔术师 / 结果前置 / 动作中段开场
- 教程方法 → 授业者 / Hormozi 句式 / 调查员
- 强观点 → 逆行者 / 预言家（需证据）
- 可见投入 → 实验家 / 代价自白 / 大数字领衔
- 冷启动陌生观众 → 点名 + 代价自白先建相关性

## 批量策略

- 一题至少跨 3 种原型产出 6–10 个钩子，标注原型，让选择发生在角度层面而非字句层面。
- 同原型内不做同义改写；跨原型才算新角度。
