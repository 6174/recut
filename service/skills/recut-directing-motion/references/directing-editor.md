# 导演语言（recut.editor）

> 全片动效取舍的速查。与 remotion-studio 的 `directing.md` 同源，但**表达介质从"代码"换成"时间线 op"**：每个动效 = 元素 params + 关键帧（`timeline.command` 的 `param`/`keyframe-upsert`），时长一律秒。
> 镜头配方见 `shot-library.md`，卡点见 `music-beat-sync.md`，字幕见 `captions.md`，口播/访谈剪辑见 `speech-editing.md`，B-roll/motion graphic 摆放见 `subject-protection.md`。

## 〇、先定结构，再时序，后润色

- **依赖顺序**：只有本次编辑会新建或改变 A-roll 时，才先冻结说话内容，再落 motion graphic/B-roll/音乐/字幕层。上游结构一变，下游重新对齐；纯视觉/音频/资产微调不重做未受影响的下游。
- 每个处理步骤单独与用户确认，确认后再动下游，不打包多个检查点。
- 方向性问题（风格/结构）在铺时间线前定案；不要铺了三层动画才发现叙事方向错。

## 一、先定"动效嗓音"：品牌 → 参数预设

不凭手感挑时长/easing，先判断品牌在哪两根轴上，再把一套 token 写进关键帧值：

- **能量轴**：低（沉稳/premium）↔ 高（运动/startup/娱乐）——决定时长、过冲、squash 幅度；
- **调性轴**：严肃（金融/医疗/enterprise）↔ 活泼（消费/社交/儿童）——决定路径曲直、次级动作多寡。

| 预设（品类） | 入场时长 | 入场曲线（2 段关键帧手感） | 过冲（scale/位移） | squash |
|---|---|---|---|---|
| 专业信赖（fintech/B2B） | ~0.7s | 缓出为主，几乎线性 | 不弹 | 0 |
| 精致高端（奢侈品/时尚） | ~1.6s | 均匀缓入缓出 | ≤1.02 | 0 |
| 活力大胆（体育/游戏/startup） | ~0.6s | 快起快落 | 1.12 | 0.25 |
| 活泼愉悦（消费/社交） | ~0.9s | 先快后慢带回弹 | 1.08 | 0.18 |
| 平静关怀（健康/教育） | ~1.4s | 对称缓入缓出 | 1.0 | ≤0.04 |
| 亲和友好（小微/社区） | ~0.87s | 柔缓 | 1.04 | 0.08 |

用法：定预设 → 按两轴微调 → 一套时长/scale/opacity 的 token 同时管入场/转场/hold 节奏。一个品牌一种动效嗓音；混用两套读作拼盘。
**实现方式**：入场 = 对 `transform.scaleX/Y`、`transform.positionX/Y`、`opacity` 打关键帧（`keyframe-upsert`）。过冲 = 中段 keyframe 越过目标值再回落。squash = 竖/横向 scale 不同步。

## 二、结构：5 秒一个节拍，一镜一动作

- **5 秒是默认节拍单位**：一个 scene（一段素材/一组元素）只承载约 5 秒和一个信息变化；长视频拆更多 scene，绝不让一个连续镜头覆盖 10 秒以上。
- 开场三秒内给钩子（结果承诺 / 反常识 / 直接问题 / 痛点警示），绝不从背景介绍开场。
- 前一段提出的问题必须由后续段落回应；结尾回收核心论点。
- **每个 scene 只讲一个主要动效**；一种动画手法（飞入/堆叠/翻页）全片只当一次主角。
- **落定后必须呼吸**：主标题/字标落定后 hold ≥ 1s；批量动效收尾 ≥ 0.5s 静止。动效排满每一帧必返工，放慢从未被否。

## 三、镜头动词 → timeline 配方

一个 scene 只选一个"主镜头动词"，落到素材（图片/视频/组件）的 transform 关键帧上：

| 动词 | 配方（素材的 params 关键帧） | 参考时长 |
|---|---|---|
| push-in（推近） | `scaleX/Y` 1→1.15，线性缓入 | 2–4s |
| pull-out（拉远） | `scaleX/Y` 1.15→1 | 2–4s |
| pan（横移） | `positionX` 0→-300（或反向），Y 不动 | 2–4s |
| tilt（纵移） | `positionY` 0→200 | 2–4s |
| drift（漂移） | 位置+微 scale 同向缓动 | 全镜 |
| dolly-zoom 意象 | scale 放大 + 文字反向位移 | 1.5–2.5s |

- **每镜只选一个主动词和一个强光学主角**；`blendMode` 的叠加/乘、mask、放大镜类效果互斥，一个 scene 最多一个。
- 相邻 scene 不要重复同一种镜头语法。先建立关系 → 解释主体 → 近景/特写落在论点、证据或结果。
- 空间动作默认 24–32 帧（0.8–1.1s）完成，之后留可读 hold。**需要解释的信息不使用剧烈运镜**。
- 字幕始终最高层（单独 text 轨，位于画面下三分之一，参数见 `captions.md`）。

## 四、导演自检清单（每个 scene 落 op 前过一遍）

1. **目标**：这个 scene 要让观众看见什么、理解什么、感受到什么情绪。
2. **镜头**：只选一个主镜头动词，不塞多个。
3. **元素运动**：元素如何进入/移动/落定；低振幅、缓慢、连续、对称缓入缓出是默认。
4. **稳定锚点**：标题/安全区不重绘、不漂移；有人脸/产品/标签时保持其形状稳定，只重构周围。
5. **收束**：非循环镜头必须说明最后如何稳定落位；复杂节奏用多个短 scene 剪辑，不塞进一个。

## 五、确定性渲染（硬性）

- 动画 = 关键帧的纯函数 f(t)。所有入场/转场/运镜用 `keyframe-upsert {ref, path, atSec, value}` 表达，**禁止墙钟**（无 `Math.random`/`Date.now`/`requestAnimationFrame`）。
- 同一素材 + 同一关键帧表在 Preview 与 Export 逐帧一致。
- 只动目标 scene；改完按帧评审，不重做未指出的段落。

## 六、来自流水线的经验

- 方向性问题（风格/结构）在铺时间线前定案；不要铺了三层动画才发现叙事方向错。
- 素材必须先经 `timeline.assets` 登记（真实 assetId），否则导出空画面。
- 装饰性 glint/泛光群发 = 廉价；批量元素入场靠运动本身，单点高质量光效可做。
- 需要代码级自定义视觉（字形描画、粒子、shader 感）时用 `component.create` 创建组件素材（见 `components.md`）；只有用户明确要求使用时才调用 `timeline.placeComponents` 落轨。
