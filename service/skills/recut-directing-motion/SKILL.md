# Recut 全局导演技能：元素动效（recut-directing-motion）

本技能是 Recut 平台 App 无关的全局导演技能，**只回答一个问题：元素怎么动**。以"观众如何感知运动的语气、节奏与落定"为决策起点，先定动效嗓音，再定单镜运动与呼吸，动效图形服务于信息而非装饰。以可读性与落定感为验收标准，不以"动得多"为标准。

## 边界声明

**本技能只管元素动效与动效嗓音；镜头运镜归 recut-directing-shot，节奏与切点归 recut-directing-editing，画面摆什么归 recut-directing-b-roll，字怎么上屏归 recut-directing-captions，耳朵听到什么归 recut-directing-sound。**

- 镜头如何运动（推/拉/横移/环绕/透视）→ 归 shot。
- 片子多快、在哪切、5 秒节拍与卡点纪律 → 归 editing。
- 一个镜头内元素如何进入、移动、落定、呼吸 → 归本技能。
- 动效图形（标题卡/数据图/关系图/章节卡）用何种形式承载信息 → 归本技能第四节，其摆放避让规则与 b-roll 共享"保护区"思想但落位判断在本技能内。
- 交界处：shot 决定"相机怎么看"，本技能决定"元素怎么动"；editing 决定"何时切"，本技能决定"落定后是否已呼吸"；b-roll 决定"放什么素材"，本技能决定"该素材上的叠加元素如何运动"。

本技能不绑定任何 App 介质，不含时间线操作、组件创建或代码语法；所有时长以秒与帧双标给出，曲线以手感词与缓动特征描述。

---

## 一、先定"动效嗓音"：能量 × 调性两轴

不凭手感挑时长与缓动，先判断品牌在两根轴上的位置，再落一套全片统一的动效嗓音。混用两套嗓音读作拼盘，一个品牌一种嗓音。

- **能量轴**：低（沉稳 / premium / 医疗金融）↔ 高（运动 / startup / 娱乐）——决定入场时长、过冲幅度、挤压（squash）强度；
- **调性轴**：严肃（金融 / 医疗 / enterprise）↔ 活泼（消费 / 社交 / 儿童）——决定路径曲直、次级动作与回弹多寡。

### 预设表（两份 directing 合并，介质中性重述）

| 预设（品类） | 入场时长 | 曲线手感 | 过冲 | 挤压 squash | 嗓音一句话 |
|---|---|---|---|---|---|
| 专业信赖 fintech / B2B / enterprise | ~0.7s / ~21f | 缓出为主，近线性，无回弹 | 不弹 1.0 | 0 | 稳、准、不抢戏 |
| 精致高端 奢侈品 / 时尚 | ~1.6s / ~48f | 均匀缓入缓出，对称 | ≤1.02 | 0 | 慢、匀、有余量 |
| 活力大胆 体育 / 游戏 / startup | ~0.6s / ~18f | 快起快落，硬加速 | 1.12 | 0.25 | 快、弹、有冲击 |
| 活泼愉悦 消费 / 社交 | ~0.9s / ~27f | 先快后慢带回弹 | 1.08 | 0.18 | 轻、弹、有亲和 |
| 平静关怀 健康 / 教育 | ~1.4s / ~42f | 对称缓入缓出，柔和 | 1.0 | ≤0.04 | 慢、柔、有呼吸 |
| 亲和友好 小微 / 社区 | ~0.87s / ~26f | 柔缓，轻回弹 | 1.04 | 0.08 | 暖、软、可接近 |

用法：定预设 → 按两轴微调 → 一套时长 / 过冲 / 挤压同时管入场、转场与落定节奏。全片统一，不在中途换嗓音。需要落地隐喻时 y 轴回弹必须可见；"专业信赖不弹"指无落地隐喻的淡入或推移类动作。

## 二、一镜一动作

- **一个画面只讲一个主要动效**：每个节拍（默认约 5 秒）只承载一个信息变化与一个主导运动；一种动画手法（飞入 / 堆叠 / 翻页 / 描边）在全片只当一次主角，重复即廉价。
- **一镜只选一个主动词**：推近 / 拉远 / 横移 / 纵移 / 漂移 / 缩放意象中只选其一；强光学主角（叠加 / 遮罩 / 放大镜类）互斥，一个画面最多一个，见 shot 的互斥规则。
- **空间动作默认 0.8–1.1s（24–32f）完成**，之后留可读落定；需要解释的信息不使用剧烈运镜，运动服务于可读而非炫技。
- 相邻节拍不重复同一种运动语法；先建立关系 → 解释主体 → 近景或特写落在论点、证据或结果。
- 默认运动取低振幅、缓慢、连续、对称缓入缓出；批量元素入场靠运动本身与错峰，不靠逐个发光。

---

## 三、落定呼吸

- **主信息落定后必须呼吸**：承载关键信息的元素（主标题 / 品牌字标 / 数字 / 网格全貌）落定后静止至少 1s 再切；品牌字标的呼吸优先于普通内容卡片。
- **批量收尾留 0.5s 静止**：大量同类元素入场完成后，满板后静止 0.5s 再切下一拍；动效排满每一帧必返工，放慢从未被否。
- **节奏宁慢勿快**：初版默认放慢一档；主体动作的完整弧线（聚焦 → 悬浮 → 归位）至少 3s；模拟真实交互（打字 / 筛选 / 点击）按真人操作速度走，观众要能跟着做一遍。
- **速度感来自加速度**：飞入与滚动一律非线性缓动与非均匀错峰，匀速直线读作廉价 PPT；群体入场用"越来越快"的硬加速节拍，最好绑定一个物理隐喻（如发牌、落位），满板后留呼吸。
- **高光与扫光宁缺毋滥**：不群发；一个画面最多给主角一次，且必须被承载元素的圆角边界裁剪；光溢出圆角是廉价感的典型来源。留下的每处光效需在正常速度下自问"好看吗"再交付。

## 四、动效图形纪律

动效图形是帮助观众更快理解信息、关系或章节的视觉层，不是把字幕包进卡片，也不是给每个节拍加装饰条。每个图形必须有明确的 viewer job。

### 1. 四个决定

| 决定 | 要回答的问题 | 必须产出 |
|---|---|---|
| Content 内容 | 哪个信息值得占用画面 | 事实、数字、关系或引语，不只是复述字幕 |
| Timing 时机 | 何时进入、停留多久、何时退出 | 语音或视觉锚点、阅读时长、持续时长、动画节拍 |
| Form & placement 形式与落位 | 用什么形式才能承载这个 job | 下三分之一标注、侧边处理、引语卡、关系图、章节卡、全幅节拍，以及候选落位区 |
| Background 背景 | 叠在片上还是拥有整幅画面 | 透明叠加或不透明全幅节拍 |

图形的形式与背景在落位前定案；最终位置与尺寸由目标画面的实际构图决定，不在创作源内预设画布坐标。

### 2. 形式与复用边界

- 身份与上下文（人名 / 产品名 / 日期 / 来源）→ 下三分之一或上下文标签；
- 关键观点与引语（定义 / 统计 / 结论）→ 引语卡、强调排版或短暂全幅节拍；
- 结构化信息（步骤 / 列表 / 比较 / 排名）→ 堆叠、对比或紧凑关系图；
- 章节与主题（开场 / 转场 / 分隔）→ 标题叠加或不透明全幅；
- 抽象关系（因果 / 循环 / 系统 / 框架）→ 关系图或循环图。

只有 viewer job、信息结构、视觉形式与画布角色四者都相同时才复用同一图形资产；只要 job 不同就新建资产，但共享同一套色彩、字体、间距、材质与运动语言。相同颜色不等于可复用。

### 3. 落位与可读性

- 透明叠加默认避开面部、口部、关键手势、产品或标志、字幕带；在剩余的最大低信息区落位，优先保证阅读尺寸而非固定角落；
- 不透明全幅是有意的视觉节拍，可以覆盖人物，但必须有明确的章节或信息承载理由；
- 文字与视觉主体在 1080p 画面中必须达到可读尺寸门槛，验收以最终像素为准，不以创作源字号为准；
- 任何裁切或落位争议以实际合成帧为准，不以资产入库状态为准。

### 4. 运动与 settled frame

- 先设计静止落定帧，再设计入场；一镜只让一个层级承担主要动作，落定后留呼吸；
- 入场约 0.8–1.2s，禁止无意义的无限循环；循环只用于氛围元素且需有明确理由；
- 文本用自然换行与网格布局，给可变长文案预留空间，不用散落的绝对定位堆砌可读文本；
- 不把图形写成界面截图、重复圆角卡片或万能表格；表面材质与光感只在视觉语言或 viewer job 要求时使用。

### 5. 代表性验证

一组相关图形在批量扩展前，至少有一个代表性图形已在目标画面中通过静止帧验证；代表性验证只证明该视觉语言适用于同类任务，不自动成为所有章节与数据图的万能模板。

---

## 五、确定性与自检

- 运动是时间的纯函数；同一组运动参数在预览与成片中逐帧一致，不依赖墙钟或随机数。
- 只动目标节拍；改完按帧评审，不重做未指出的段落。
- 每个节拍落位前自问：要让观众看见什么、理解什么、感受到什么情绪；是否只选了一个主运动；落定后是否有呼吸；关键信息是否稳定可读。
