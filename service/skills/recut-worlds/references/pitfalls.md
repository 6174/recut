# 常见误用

> `recut-worlds` 的二级参考。误用的完整清单（入口不重复展开）。

- **把 world.md 当操作手册**：它是内容 / 生产工作流；工具怎么调看本技能。
- **还在用「证据」概念**：素材唯一表示是 **media 属性**；不要创建独立素材层。
- **在画布上复制属性值**：属性卡只连边、持投影；真相在 `entity.attrs`。
- **把长文 / 编辑控件塞进实体卡**：卡片只略读，编辑走面板或属性卡。
- **把正文写进 attr、让 `detail`（正文）空着**：作品顶层设想、脚本细节、视频段拍摄设计**都是正文**，必须写 `detail`；attr 只放真 meta。后续生成提示词正是从这些正文里长出来的。
- **写 Canon 不等授权**：无用户明确请求就 upsert / promote 是越权。
- **忘记 `expectedRevisionId`**：并发写会静默覆盖，必须带乐观锁。
- **替用户确认视频生成**：视频由平台落为待确认资产；自行确认、把直生当默认、或自行轮询采纳都是越权；确认只属于用户。
- **世界生图 / 生视频不带参考图**：不先读 world.md 资源口径、不用 `entities.get` 取实体 media 参考就纯文本直出，是最严重的误用——主角色会漂、场景 / 风格会串。画面可能出现主角色却没有 `role="character"` 时**必须停下补齐**。
- **把封面塞进动态 attr**：封面是一等字段 `cover`（显式优先、否则从 media 属性推断），不是可删可改名的 attr；旧 `background` 只是普通装饰 attr，平台不识别其封面语义。
- **角色说话却不带声线参考**：只传 `imageAssetIds`、丢掉 `references`/`audioAssetIds`，或让 VO 走默认音色——角色声音会与 Canon 不一致；有台词必须带 `role="voice"`。
- **等生成成功才落位**：拿到 `assetId` 就应**立刻**落节点（`assetStatus:"generating"`；视频含待确认态）；用 `recut.job.wait` 把落位堵在终态之后会让用户干等，违背无限画布的即时反馈。
- **只写实体属性、不落画布节点**：用户要的是画布上的「图片节点 + 属性边」；只写实体 attrs 不会出现节点。两者都要做时 `label` 保持一致。
- **在画布元素上写语义真相**：语义只存实体 / 关系；画布只承载投影与表达。
- **把画布当文件夹**：一层层套内层画布做分层（如 `work → script` 再逐级各占一层）。相关联的内容应尽量放同一张画布——一个作品的脚本与视频节点全铺在作品层这一张，别逐级下钻。
- **为「归类」造空容器实体**：分组用类型 / 关系 / 位置表达，不要造空目录。
