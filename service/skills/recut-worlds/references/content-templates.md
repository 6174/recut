# 正文模板：work / script / scene / shot 的 `detail` 骨架

> `recut-worlds` 的二级参考。只写剧情梗概不合格——这些正文是后续生成提示词的料场。

## 作品 `work.detail`：先把该作品的完整内容表达出来

按类型写足内容本体（**故事类像小说一样写全**：因果、场景、**人物对白逐字**；广告写完整广告故事 / 创意；其他类型写足其内容本体）：**一次写全、不压缩、不跳步**。

```markdown
# 作品：<名>
## 定位与体量：给谁看、想表达什么、大约多长 / 几集
## 完整故事（正文主体，小说式一次写全）
- 世界与人物：谁，什么处境，彼此关系
- 因果推进：起因 → 阻力 → 一次次转折 → 代价 → 结局（每一步都写清"为什么此刻发生"）
- 关键场景细节：重要场面写到可复述具象（地点/动作/情绪/环境/道具）
- 关键对白：重要对话**逐字**写出（谁对谁说、语气、反应）——对话是真实感与后续台词 / VO 的来源
- 环境与旁白素材：时代/节气/空间/声音，够日后写 VO 与调度
## 主题与调性、版权/审核边界
```

> **为什么必须先写全**：作品正文是「整部片子的内容本体」。**压缩表达（把 40 分钟的内容塞进 3 分钟脚本）一定出不了电影感**——只有内容在作品层被充分写出，后面分集、拆场才有整体与细节设计。**生成的视频不会漏掉你写足的内容、也不会替你压扁时间进展；反过来，作品层没写出来的，成片里就没有。** 先写足，再拆。

## 视频脚本 `script.detail`：从中拆出的「一集」完整脚本

**一集 = 一个 `script`**，一个作品可多集。

```markdown
# 第 <n> 集：<名>（对应作品故事的 <段落/幕/章>）
## 本集结构：钩子 → 推进 → 转折 → 落点（与前后集的接续关系）
## 逐段脚本（正文主体）
- 旁白 VO：「逐字…」
- 台词：角色A：「逐字…」；角色B：「逐字…」
- 画面意图：这段发生什么（镜头运动留给场次/镜头）
## 场景初步规划：场次清单（地点 / 人物 / 发生什么 / 预计时长）
```

**分集纪律（防压缩）**：分集依据是**内容的天然结构**（大转折 / 幕 / 章节 / 段落），不是把总时长硬切成 N 段等长；每集时长与内容由内容本身定，**不为"塞进某个时长"砍内容**。作品内容没写全、无法 cold-read 复述整条因果前，不动手拆集。

## 场次 `scene.detail`：一次视频生成的完整导演文件

**一个场次 = 一次生成**：场次总时长必须落在模型单次上限内（默认 ≈15s）——内容超过就**拆成多个场次**，而不是拉长单场。镜头是这一场内部的分镜，不改变「一场一次生成」这个粒度。

**场景正文的主角是「真正拍摄的逻辑」**——空间 / 美术 / 表演调度 / 摄影 / 灯光 / 声音 / 视效；剧情只是它们要服务的目标。骨架对齐 `recut-director（references/generation-prompt）` 与各 Mode 的 `video-prompt-guide`。

```markdown
# 场次 <n>：<名>（一次生成；目标时长 <N>s ≤ 单次上限，默认 ≈15s）
## 0 参考与全局（本段声明一次）
- 参考职责：逐张说清细节（按真实连接顺序）——是什么 / 锚定什么 / 需保持一致的关键特征
- 角色绑定：固定角色名 + 2–3 个稳定特征 + 当前服装版本
- 场景与时刻：地点 / 时间 / 天气 / 空气 / 重要背景实体 / 开场人物位置
- STYLE LOCK（≤2 行 / ≤80 字，逐字冻结；禁引擎/渲染词）：媒介 + 主光与影调 + 色调
- 无字锁：不需要屏幕文字就写「全程不生成任何字幕与屏幕叠字」；需要则逐字列
## 1 空间与美术：前中后景、固定陈设、地面/墙面/天空、入口通道、材质与表面、主辅色、道具结构
## 2 表演与调度（blocking）：动作链（执行者/部位/方向/路径/速度/幅度/先后/接触点/受力/惯性/衣发反馈）+ 表演（视线/眼神/眨眼/口型/呼吸/下颌/肩背/手指/重心/停顿）
## 3 摄影（CAMERA LOCK + 每镜机位）
- CAMERA LOCK（≤1 行 / ≤30 字；禁机身品牌）：焦段 + 景深 + 稳定 + 畸变呼吸（全片一套）
- 每镜：机位（主体哪侧/离地高度/俯仰/朝向）、景别、起始构图、主体画面位置、前景遮挡与背景尺度
## 4 灯光：光源位置/方向/硬柔/强弱/冷暖/光比、阴影与反射变化、主辅色
## 5 镜头序列（累计区间领起，连续相接）
- [0~3s] 空间与起始构图 + 单一主导运镜（起点/方向/速度/路径/停止位置/结束景别）+ 动作与结束状态
- [3~7s] HARD CUT。同上，承接上一镜结束状态
## 6 声音设计（两层，缺一不合格）
- 底声：持续环境底噪 + 有无 BGM 及气质（无 BGM 明写）
- 局部声：按动作点的脚步/衣料/道具/碰撞/人群/对白；对白逐字、标说话人、标音色
## 7 视效逻辑（若有）：起点/路径/速度/规模/可见反馈/终止状态
## 8 画内文字：要可读就逐字写死（引号、单条 ≤15 字、逐条位置层级、载体占足够像素）；否则写无字视觉编码
## 9 结束状态与切点：人物/道具/环境/光线/焦点/景别/声音分别停在哪，在哪个可见或可听事件上硬切
## 参考锚点（role，不含 storyboard）：character / environment / prop / style-ref / voice / motion-ref
## 生成备注：模型/画幅/时长意向（ratio/resolution 等技术参数只记这里，不写进提示词正文）
```

## 镜头 `shot.detail`：单镜细节（生图 / 关键帧提示词的料场）

```markdown
# 镜头 <no>（时长 <N>s）
## 空间与时刻：前中后景/陈设/地面/入口；地点/时间/天气/空气
## 摄影：机位（主体哪侧/离地高度/俯仰/朝向）、景别、起始构图、焦段/景深/稳定、主体画面位置、前景遮挡与背景尺度
## 动作链：执行者/部位/方向/路径/速度/幅度/接触点/受力/惯性/衣发反馈/结果
## 表演：视线/眼神/眨眼/口型/呼吸/下颌/肩背/手指/重心/停顿
## 摄影机运动：一种主导（起点/加速或匀速/方向/路径/距离变化/停止位置/结束景别）+ 焦点转移
## 灯光与美术：光源位置/方向/硬柔/冷暖/光比、材质/服装/道具/天气/阴影反射
## 连续性锚点：承接上一镜结束状态（位置/朝向/持物/光位/服装/道具）
## 声音：动作声/环境变化/对白（逐字，标说话人）
## 画内文字：逐字写死，或声明无字并给视觉编码
## 视效（若有）/ 结束状态与切点
## 参考锚点（role）
```

> 提示词的固定形状（`[CAMERA LOCK]` / `[STYLE LOCK]` / 参考锚定表 / 镜头基调 / 声音设计 / `[起~止s]` 镜头序列 / 负面约束）与选型规则见 `recut-director（references/generation-prompt）`。**场次 / 镜头正文就是它的料场**——正文里没有空间、表演、摄影、灯光与声音，提示词就长不出来。
