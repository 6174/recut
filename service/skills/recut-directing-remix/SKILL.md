# Recut 全局导演技能：混剪与仿拍（recut-directing-remix）

本技能是 Recut 平台 App 无关的全局导演技能，**只回答一个问题：从已有视频反推并产出新片？** 适用范围为一切以“已有视频”为输入、以“新的短视频成品”为输出的二次创作：A 方向是长转短（从一支长视频中选段、重组成多支竖版短片），B 方向是爆款仿拍（从一支或多支爆款视频中反推可迁移的情绪公式与结构，再落到新选题上）。以“是否有一个可被新选题复用的结构化判断”为验收标准，先反推，再选段或迁移，最后才谈执行。

## 边界声明

**本技能只管「反推与选段」决策；钩子形态与留存结构归 recut-directing-hooks；切点密度、转场与卡点组装归 recut-directing-editing；画面该放什么、怎么摆归 recut-directing-b-roll；字幕样式归 recut-directing-captions。**

- 钩子写成什么样、原型选哪一类、首帧三层如何对齐，由 hooks 回答；本技能只在已拆解的钩子结构之上，判断“哪一段的钩子值得迁移、哪一句开场白值得保留”。
- 选段之后的精剪——在哪里切、切多快、用什么转场、是否卡拍——由 editing 回答；本技能只决定“选哪段、起止落在哪句完整语义上、是否需要自然切点修正”。
- 选段后的竖版重构——人脸居中、字幕安全区、PiP 或全幅 cover——由 b-roll 回答；本技能只决定“是否需要竖版重构、按何种裁切策略重构”。
- 本技能不决定新片的视觉风格与配乐情绪（归 motion / sound），也不决定发布规格与平台雷区（归 platform）。交界处以本声明为准。

## 方向 A：长视频 → 短片（Long-to-Short）

方向 A 的决策对象是**同一支长视频内部的候选段落**。不做“看一遍凭感觉剪”，而是以转写文本为锚，先打分、再经人工批准、再修正边界、最后决定竖版形态。

### A1 转写是唯一可信锚点

- 以词级时间戳的转写为选段底座，而非以时间轴或画面直觉为底座。转写需包含逐词时间、对齐的句级分段与说话人归属（如有）。
- 转写后做一次轻度清洗：删固定无语义口癖、修正明显错听词、合并残句；清洗只改文字，不改时间戳，切点仍以原时间戳为准。
- 未完成转写校对前，不进入候选打分；“先看懂再剪”是硬门槛。

### A2 选段标准：五维加权，不只看热闹

候选以 15–55 秒为默认容器（按平台可收窄至 21–34 秒），单支长视频产出 8–12 个候选，再按五维加权打分排序：

| 维度 | 权重 | 通过判据 |
|---|---|---|
| 钩子强度 | 0.30 | 前 3 秒是否有具体主张、数字、代价或结果前置；能否一口气说完 |
| 独立完整性 | 0.25 | 脱离上下文是否仍成立；是否有完整“主张→论据→兑现”闭环 |
| 情绪浓度 | 0.20 | 是否有强观点、意外揭示、幽默或代价自白；是否可被一句话复述 |
| 价值密度 | 0.15 | 单位时间内的可执行信息、数据点或框架密度 |
| 收口质量 | 0.10 | 是否有可感知的 punchline、揭示或单一 CTA；是否值得收藏或追问 |

- 加权分 0–100，低于阈值（默认 60）的不进入人工比稿；阈值按长视频信息密度上下浮动。
- 每个候选必须写清：起止时间戳、首 3 秒钩子句、入选理由一句话。
- 钩子强度与独立完整性合计占 0.55——两者不过关，其他维度再高也不入选。

### A3 人工批准门：不经确认不渲染

- 候选打分后必须以表格形式呈报，等待人工选择“全部 / 指定编号 / 全部不通过重打分”。未获批准前，不做任何渲染或导出。
- 人工可做三类调整：增删候选、微调起止、指定字幕样式与目标平台；调整后需二次确认。
- 批准结果落为 `approved_segments` 清单，作为后续所有步骤的唯一输入；后续只改边界，不改清单构成。

### A4 自然切点：边界必须落在语义与静默的交点

- 批准后的起止必须做一次音频感知的边界吸附：优先对齐到词边界，其次对齐到句边界（句号/问号/感叹号后），再以静默检测到的自然停顿做微调（默认末尾补 300ms 呼吸）。
- 起点优先句首，终点优先句尾；若句尾 3 秒内有更完整的收口，则向后延伸至该收口。
- 强制约束：最短 5 秒、最长 60 秒，不切在词中、不切在半句中；吸附后的位移需向人工回報增量。
- 边界吸附完成后的清单为最终渲染输入；此后不再回头改选段。

### A5 竖版重构决策：按内容类型定版式

- 根据源内容类型决定重构策略，而非一律居中硬裁：
  - **口播人像**：以人脸追踪为锚的居中 9:16 裁切，眼睛落上三分之一，口播字幕避开人脸与平台遮挡。
  - **录屏/演示**：以内容可读性为锚的居中加暗边框，保留完整界面与关键文字，不为填满画幅而裁掉信息。
  - **访谈/播客**：按说话人分屏或居中裁切，保持说话人与字幕的对应可读。
- 版式决策在边界吸附后做出，每段独立判断；同一长视频的不同段可采用不同版式。

## 方向 B：爆款拆解 → 公式迁移（Viral Breakdown → Riff）

方向 B 的决策对象是**已有爆款视频背后的可复用公式**。核心纪律是 **riff the formula, not the video**——迁移的是情绪机制与结构节拍，不是画面与台词的复刻。

### B1 拆解深度：四件套为底线

对每一支对标视频，拆解需覆盖：

1. **源与关键帧**：保留源片段与按节拍抽取的关键帧/接触表，作为“画面在说什么”的证据。
2. **转写与说话人**：逐句转写 + 说话人角色归属 + 场景与镜头节拍标注。
3. **钩子与节拍**：前 3 秒与前 5 秒钩子的具体形态（视觉/口播/文字三层）、剧情节拍、冲突与升级、反转与兑现。
4. **评论区共振**（如可得）：高赞评论的情绪、重复出现的观众立场、观众为何评论、创作者可借鉴什么。

- 拆解产出需区分“可迁移的结构”与“不可复制的内容表面”；未做此区分的拆解视为未完成。
- 通用迁移场景下，不强制绑定到特定账号或行业；若用户指定目标账号，则改写为面向该账号的迁移建议。

### B2 反推公式：抽出情绪路径，而非复述剧情

- 从拆解中提炼**情绪公式**：观众在每个节拍前的心理状态 → 该节拍的机制（注意/兴趣/兑现/召唤）→ 状态迁移后的心理。公式以“状态—机制—新状态”的链条表达，而非以“先发生 A 再发生 B”的剧情复述表达。
- 标记每个节拍的**意义契约**：观众在此刻被承诺了什么、最终以何种表面兑现、用什么感官通道承载、靠什么锚点留存。
- 标记**约束条件**：该公式成立的前提（人群、场景、可演示性、代价可信度），脱离约束的迁移视为无效迁移。

### B3 迁移到新选题：只换表面，不换路径

- 选定新选题后，以“公式节拍 × 新选题卖点/角度 → 观众心智位移”的句式，写出本条的 `content_anchor`（创意锚点）。锚点需具体到可执行：哪一拍用哪一表面、哪一功能点对应哪一情绪机制、观众从什么认知移到什么认知。
- 三条纪律：
  1. **只说与源不同的部分**，不重复公式已有的部分；改动越小，锚点越短。
  2. **每个改动都要定位**——落在第几拍、之前是什么、之后是什么；无定位的改动视为未定义。
  3. **不同轴分开写**——拍法（光感、颗粒、运镜）与内容（服化道、场景、道具）分开表述，不混为一句。
- 若新选题的某个卖点无法在公式约束内兑现，则判定该选题与该公式不匹配，应换公式或换角度，而非硬套。

### B4 不复制内容的红线

- 不复制源视频的台词、字幕文案、画面构图与人物肖像；所有表面需为新选题重写。
- 不做无后续的假悬念迁移；悬置类钩子仅在确有续集或评论区追问可承接时迁移。
- 以“若把表面换成任意其他话题仍成立，则锚点无效”为校验；有效的锚点在换话题后应失效。

## 工作流与校验

1. **定输入即定方向**：输入为长视频文件 → 走方向 A；输入为爆款链接/对标视频 → 走方向 B；两者可串联（先 B 拆解公式，再 A 选段验证），但每一步的方向需显式声明。
2. **先转写/拆解，再打分/反推，再批准，再修正边界/写锚点**：不跳步；转写未校对、拆解未区分可迁移与不可复制前，不进入下一环节。
3. **人工批准是唯一硬门槛**：A 方向的候选清单、B 方向的公式与锚点，均需人工确认后才进入渲染或新片生产。
4. **边界与锚点需回報增量**：A 方向回報每段的边界位移量；B 方向回報锚点中每个改动的落位与校验结果。
5. **收口前复检**：逐段自问“下一秒凭什么让人留下”，删掉一切不抬高代价或不推进情绪的句子；确认单一 CTA 与循环或闭环机制是否就位。
