# Recut 全局导演技能：开场钩子与留存（recut-directing-hooks）

本技能是 Recut 平台 App 无关的全局导演技能，**只回答一个问题：开场怎么留人、结尾怎么收**。适用范围为一切需要争夺注意力的短视频与中短视频的 0–3 秒开场与完播留存设计。以“观众在前三秒是否决定留下、到结尾是否愿意留存或复看”为决策起点，先定钩子，再定留存路径。

## 边界声明

**本技能只管 0–3 秒开场与完播留存机制；整体叙事结构归 recut-directing-story；叙事节奏密度归 recut-directing-editing。**

## 一、钩子的本质：闸门而非装饰

- **前 1.5–3 秒决定分发是否继续。** 平台在该窗口内完成早期留存判断，钩子失败则后续内容无机会被看见。绝不从背景介绍、问候语、品牌开场白入场。
- **一个钩子是猜测，一批钩子是策略。** 每次给出 6–10 个钩子，覆盖至少 3 种原型，让创作者选角度而非仅改字句。
- **具体胜过聪明。** 具体名词、奇数与精确数字、具名代价，比模糊的“你绝想不到”更能留人。钩子写不出来，往往是选题本身立不住。
- **承诺必须兑现。** 钩子许诺什么，正片就必须在可见时间内交付什么；以夸大换点击、以偏离换完播，会同时失去算法信任与观众信任。
- **提升概率而非保证结果。** 钩子只改变留人概率，不承诺必爆；用“倾向于、更可能”表述，不做必爆断言。

## 二、三层钩子：视觉 / 口播 / 文字

钩子在开场 1–2 秒内并行跑三层，缺一即残缺。对齐的三层读作必然，错位的三层读作混乱。

### 1. 视觉层（眼睛先到）

- 首帧即交付冲突或结果：成品、对比、前后对比的“后”、强烈情绪、并列陈列。不是一张等待开口的静态人脸。
- 按“暂停即清晰”构图：观众在信息流中拇指停下的瞬间，首帧必须已可读；若需再看 2 秒才明白，就不是钩子帧。
- 用运动做视觉打断：推近、急切入、手入画、跳切、缩放，任一打破信息流匀速的动作即可重置注意力。
- 构“待续播放”帧：画面定格在动作中段，让人产生“点开看接下来”的本能；不在片头放标志、倒计时、渐显黑场。

### 2. 口播层（耳朵后到但定调）

- 5–10 字、一口气说完，在第 2 秒前落地；同时承担检索与信息传达。
- 句首即抛结果或代价，如“你那套 3000 元的咖啡装备，正是难喝的原因”，而非“大家好今天聊聊咖啡”。
- 一句只说一个主张，不铺垫、不自传、不加“其实、然后、基本上”。
- 动词要有力：用“烧掉、砸掉、拆穿、拿下”替代“花费、弄清、达到”；动词带出运动与代价，弱动词带出会议感。
- 能量与画面一致：高代价的句子配静止空镜，会被感知为脱节。

### 3. 文字层（静音时的钩子）

- 首帧叠加 3–7 字的屏上文字，作口播的压缩与锐化，而非复读。
- 规则：去动词、去冠词、保留数字、保留对比。口播说“我花了 4000 元试遍咖啡器材，最后只留这台 399 的”，文字写“4000 → 399”。
- 一屏一个主张，高对比、居中或居上三分之一，避开平台界面遮挡；首词即是最有吸引力的词。
- 校验：遮住文字，静音只看画面是否仍留人；遮住画面，只看文字是否仍让人停留。两者都应独立通过。

### 4. 可选第四层：声音设计（对齐节拍）

- 首切上的重拍、心跳骤停、留白静默，是把前三层钉在一起的节拍器；与画面切点对齐时成立，错位时即是噪音。

### 对齐顺序

先写口播句（读出来掐时长），再设计首帧让它在声音落地前已完成表达，最后写文字作压缩；四层同指一个主张。

## 三、钩子原型分类与选型

原型是起手形状，不是教条。同一选题至少试 3 种原型，再比稿。

| 原型 | 一句话形状 | 何时选用 |
|---|---|---|
| 预言家 | “这类东西即将改变某群人做某事的方式” | 有真实演示支撑的趋势判断 |
| 实验家 | “我用 X 时间做了 Y，只为验证 Z” | 可见的投入与对比过程 |
| 授业者 | “某人用反直觉方法拿到某结果” | 教程、方法论、可复现结果 |
| 魔术师 | “看这个，它其实是…” | 视觉本身即钩子，口播只作指针 |
| 调查员 | “我在熟悉之地发现被忽略的东西，它能…” | 稳健命中、方差低的基线款 |
| 逆行者 | “人人都以为 X 是因为 Y，错，真相是…” | 有证据支撑的强观点，峰值高、方差也高 |
| 代价自白 | “我替你烧掉 N 元/ N 小时，结论只有一句” | 数字即信用，替观众承担试错成本 |
| 具名点名 | “如果你是某类处境的人，这条就是给你的” | 精准收窄人群，以相关性换留存与收藏 |
| 悬置 withholding | “结果我先给你看，方法与品牌先不说” | 揭晓本身即价值，评论区追问驱动留存 |
| 数值清单 | “3 个事 / 5 步 / 7 错” | 容器清晰、易配屏上计数器与快节奏 |
| 直球提问 | “为什么没人说某件反常的事？” | 仅当问题本身足够锋利时使用 |
| 结果前置 | “人人追问我是怎么做到的” | 借已发生的关注势能开场 |

选型捷径：

- **有强视觉结果的选题**（演示、前后对比、开箱）：魔术师、结果前置、动作中段开场。
- **教程与方法**：授业者、“如何达成某结果且无需某痛苦”的句式、调查员。
- **可证伪的强观点**：逆行者、预言家；前提是正片真能自证，否则信任崩塌。
- **可见的高投入**：实验家、代价自白、大数字领衔。
- **面向陌生观众**：点名与代价自白先建相关性与信用，再开悬念；硬广式的“钩子—故事—诉求”在冷启动中需把诉求软化。

打磨钩子句的常用手法（择 1–2 个叠加即可）：加一个精确数字、加一句半秒信用背书、把泛指换成具名对象、把首三词换成最锋利的词、把弱动词换成强动词、加一句反常识对冲、把陈述改成悬置（先不给答案）。

## 四、留存结构：钩子 → 爬升 → 兑现 → 收口

单条视频的留存脊为四段，段间用“但是 / 因此”衔接，不用“然后”。

- **钩子（0–3 秒）：** 打开一个待闭合的环，或立下一个可感知的代价与结果。
- **爬升（中段）：** 逐层加码具体性、证据或冲突，让好奇心复利增长；绝不原地踏步。每 2–3 秒给一次视觉或文字重置（切镜、变景、文字刷新），防止“已看够”错觉。
- **兑现（payoff）：** 清晰、可见地交付钩子许诺；若钩子悬置品牌或方法，此处即揭晓。把最强瞬间留给兑现，把次强瞬间前置到靠近钩子的位置以扛住早期流失。
- **收口（CTA）：** 只提一个低摩擦动作，且与兑现直接相关，如“收藏下次用”“评论区打出关键词”“关注看下一集”。不做多重诉求绑架。

三种失守与对治：

1. **钩子失守（1 秒内走人）：** 首句平、泛、慢或以品牌自我为先。对治：换更锋利的原型，句首即给结果或代价。
2. **爬升失速（中段流失）：** 开场尚可，随后平铺无增量。对治：提前打开待闭合的环、重排使张力递增、插入中段再钩子（“但真正关键的是下一句”）、删掉一切不抬高代价的句子。
3. **兑现迟埋（好戏太晚）：** 精华压在末尾，观众等不到。对治：把兑现或其预 taste 前移，压缩铺垫，并在钩子中预告兑现的类别（让观众知道等的是哪类答案）。

节奏提示：钩子要快，中段可略作呼吸以安放一次高光，结尾要极快；结尾收得干净或回扣开场，更易触发重播。

## 五、结尾与留存机制：收口、循环、CTA

结尾不是总结陈词，是为留存与分发服务的机制设计。

- **闭环式收口：** 首尾互文，让最后一句改变第一句的含义，观众因“重看一遍才懂”而复播。适用于观点与洞察类。
- **循环式结尾：** 末帧画面与首帧在构图或动作上可无缝衔接，配合末句回扣首句，形成物理循环。信息流自动重播时体感为一次完整的二次观看。
- **悬置式收口：** 当内容天然分集时，结尾只兑现本集承诺，同时打开下一集的环（“下一条拆第二步”）。仅在确有续集时使用，不做无后续的假悬念。
- **CTA 单一性：** 每条只保留一个收口动作；收藏导向（工具、清单、步骤）、评论导向（提问、填空）、关注导向（追更）三选一。把 CTA 文案写在口播与文字两层，不只放在口播。
- **末帧即封面意识：** 最后一帧应与首帧一样经得起暂停审视，字形清晰、主体居中；避免以渐黑或空镜收尾浪费末次曝光。

## 六、反模式：开场即流失

出现即改写，不做解释：

- 问候与频道自报（“大家好欢迎回到…”）、标志动画与频道歌——每帧都是流失。
- 模糊悬念（“你绝对想不到接下来发生了什么”）——无类别的悬念被判为诱饵。
- 承诺与交付不一致——点击感被骗即回跳，信任与分发同时受罚。
- 先要关注再给价值——观众尚未获得任何回报，诉求被感知为冒犯。
- 用故事年代学开场（“几年前有一次…”）——应从故事最锋利的瞬间切入，再回溯。
- 面向镜头的长宣告（“今天我们来讲…”）——宣告“将要讲”不如直接“正在讲”。
- 命令式挽留（“别划走、听我说”）——仅当后续真有高代价或强反差时成立，否则更显急切。
- 单层钩子（只有口播锋利，首帧与文字空白）——静音观众直接划走。
- 以品牌为先（“看看我们的新品”）——以观众结果或痛点为先，品牌在兑现中自然出现。
- 需解释才懂的巧思——首秒要清晰而非机巧，巧思留给兑现。
- 钩子被埋在第三句——删掉前两句，第三句往往才是真钩子。
- 钩子自身演成 10 秒小短片——钩子应在 3 秒内闭合一个小环，而非自成起承转合。

## 七、工作流与校验

1. **定题即定钩：** 选题通过性以“能否写出 3 个可信钩子角度”为判据；写不出则重定选题。
2. **批量比稿：** 同题产出 6–10 个钩子，分属不同原型；每个钩子写清口播句、首帧画面、屏上文字三层。
3. **过清单：** 是否有具体名词与数字、兑现是否可见或可预期、无口头清嗓、3 秒内是否闭合小环、静音是否成立、承诺与正片是否一致。
4. **对位试拍：** 择 2–3 个最强钩子实拍，以前三秒留存定胜负，而非以主观喜好定稿。
5. **中段与结尾复检：** 逐段自问“下一秒凭什么让人留下”，删掉一切不抬高代价的句子；结尾确认单一 CTA 与循环或闭环机制是否就位。
