# Recut 全局导演技能：声音设计（recut-directing-sound）

本技能是 Recut 平台 App 无关的全局导演技能，**只回答一个问题：耳朵听到什么**。适用范围为一切需要以声音承载情绪、信息与节奏的成片——口播、解说、产品宣传、AI 生成段落混排、竖幅短视频。以"观众闭眼只听亦能感知结构、睁眼视听一致、且无版权与听感硬伤"为验收标准，先定耳朵文案，再定表演方向，再定音乐与音效层次，最后过版权与听感纪律。

## 边界声明

**本技能只管声音的听感决策；以下交界归口，以本声明为准，互不重叠：**

| 决策 | 归属 | 说明 |
|---|---|---|
| **BGM 的卡点与切点落拍、节奏密度与段落节拍** | `recut-directing-editing` | 本技能定 BGM 选什么气质、SFX 用什么词汇与层次，落拍的数学纪律与密度分层归 editing |
| **口播文案的语义取舍（留哪句、删哪句、是否重拍）** | `recut-directing-a-roll` | a-roll 定"留与删"的语义判断，本技能定留下的话"怎么写才好听、怎么演才可信" |
| **字幕的可读样式与强调词、封面标题文案** | `recut-directing-captions` / `recut-directing-platform` | 字幕怎么摆才可读归 captions，标题与封面规格归 platform；本技能只决定声音与字幕的互补关系（VO 支撑字幕、音乐不与人声打架） |
| **画面该放什么素材、怎么摆** | `recut-directing-b-roll` | 画面选材与版式归 b-roll；本技能只在已定画面结构之后决定声音如何托住画面 |

未点名处，本技能为声音听感的唯一权威；与上述技能冲突时以本表为准。

## 一、为耳朵写作的 VO 规则：把眼稿译为耳稿

好 VO 的 80% 是"写给耳朵的稿"，20% 才是工具。眼稿直接喂给语音模型，是机械感的首要来源。

- **为听而写，不为看而写**：用口语缩写与短句，一口气一意。中文每句承载一个完整意群，英文用 contractions（you'll / it's / we're），避免博客段落与 bullet 列表的照搬。
- **一气一意，句长错落**：长短句交替，形成自然呼吸；连续三句等长即为节拍器失守，需重排。
- **句首即抛结果或动词**：把结论、动词、数字前置，不以"大家好、今天我们来聊聊"之类问候或背景铺垫开场。弱动词（花费、弄清、达到）换强动词（烧掉、砸掉、拆穿、拿下）。
- **大声读出来**：写完必读一遍，拗口处必改；绕口、多级从句、生僻术语加注音说明或改写为通用口语。
- **不贴眼稿格式**：模型看不见加粗、分级标题与项目符号；所有格式必须译为可被听见的停顿、重音与衔接词。
- **静音共生**：默认视频在静音环境首刷，VO 支撑字幕而非替代字幕；VO 的关键信息必须能在字幕中独立成立（见 captions 技能）。

验收：遮住画面只听 VO，逻辑是否成立、节奏是否可跟；遮住声音只看字幕，信息是否仍可读。两者皆通过才算耳稿合格。

## 二、声音表演方向（delivery direction）：选声与定向

选声与定向是导演动作，不是参数随机。同一段耳稿，用不同表演方向会给出完全不同的可信度与情绪。

### 1. 选声匹配

- **三类声源**：曲库/商用声库的现成声、按提示词设计的声、已获明确授权的本人克隆声。声库选择需同时贴合品牌书面嗓音与平台调性（如产品发布会的克制稳重 vs 短视频的松弛直接）。
- **书面嗓音与听觉嗓音一致**：品牌的书面语气决定听觉声线的气质基调，两者不割裂。
- **拟人红线**：未获被模仿者书面授权，不得克隆真人声线；商业用途不使用名人相似声。授权流程与身份校验视为硬门禁。

### 2. 按任务选模型气质

- **高表现力短句**（Reel / Short / 钩子段）：选最具表现力的模型气质与情绪标签能力，允许用克制的情绪标签与停顿标记（如轻柔、耳语、半拍停顿）作定向。
- **长段平稳解说**（教程、长视频、课程、有声段落）：选长段稳定性优先的气质，保证段落一致性优于单句峰值。
- **草稿与实时试听**：用轻量、快速的气质先跑通节奏与耳稿，再以终版气质重渲定稿；草稿不等同交付。

### 3. 定向三杠杆

- **情绪与停顿**：情绪标签克制使用，一句至多一处；重在停顿与重音落点，而非堆叠标签。标签服务于"这一句要让观众听到什么"，而非装饰。
- **稳定性与相似度**：偏表现力时稳定性取中低区间、偏一致性时取中高区间；相似度取中高区间，顶满易引入采样瑕疵。同一条稿生成 2–3 版择优，坏句单句重渲而非全篇重做。
- **发音校准**：人名、品牌、术语、数字与中英混排处，预先给出注音或音标提示；成片试听不过即改写原文而非反复调参。

## 三、BGM 选型与 SFX 层次：先铺骨架，再钉层次

**顺序铁律：画面结构基本锁定 → 先铺 BGM 定能量骨架 → 逐拍钉 SFX。** 画面未锁定前不钉帧，换 BGM 与改画面不混在同一轮，否则全表重钉（二次返工的重灾区）。

### 1. BGM 选型四判据

- **能量曲线对齐**：BGM 的能量起伏必须托住分镜的能量曲线（低开 → 中段推进 → 尾段峰值）。候选曲必须垫进成片试听，单听曲库无法判断气质。
- **鼓点与节奏感优先**：产品宣传与信息型成片，优先电子鼓底（tech-house 类）的稳态律动；"好听/欢快"是次要判据，旋律过抢的曲子会与拟音打架。
- **片种气质一耳朵检验**：闭眼只听音轨，应像发布会预告而非游戏试玩。合成器 pluck / bloop / 卡通弹跳等游戏化音色，在产品宣传片中视为气质失配。
- **可托 SFX 层次**：平稳鼓底优于大起大落的旋律，留出 headroom 供拟音层次叠加；全片一条主 BGM 铺底，首尾以淡入淡出收边。

### 2. SFX 词汇表：按片种选，不按事件选

- **五个基础词**：whoosh（运镜）、impact（落地钉点）、riser（铺垫）、sparkle（光效）、transition（转场）。五个词覆盖八成转场与运镜，其余为"贴画面定制"槽位。
- **拟音层**：真实动作拟音（键盘/快门/纸张/碎裂/流体/人群）按画面动作按需选用，泛用 swoosh 盖不住有辨识度的动作（如打字揭示必配键盘声）。
- **音色禁区**：禁用整包游戏化音色的合成反馈音；单文件需逐个试听判别，凭目录名或文件名放行视为失守。

### 3. 钉帧与层次纪律

- **逐拍钉帧、声明式集中管理**：每条 SFX 登记"对应画面动作 + 钉帧位置 + 响度"，与分镜表对照存放，不凭感觉铺音。
- **钉相对，不钉绝对**：钉帧位置写为相对所在镜头起点或拍号的偏移，换曲或改前段时长时只改零点与拍长两常量，全表自动跟随；裸写绝对帧号视为债务。
- **时长等长**：音频时长与画面动作严格等长，长样本按动作时长截断而非任其播完。
- **响度分层**：BGM 打底压低给 SFX 留 headroom，常规 SFX 按"这一拍多重要"在常规区间内分层，最重一拍给全片峰值。钉完必以成片试听验收，不以数字为准。
- **防机枪感**：同类连发不用单一文件机械复读，靠"近似双样本交替 + 音量阶梯递减 + 间隔跟随画面加速收缩"做节奏，密到糊成一片时主动淡出为一条 swoosh。

## 四、平台版权红线：以"不会被静音、被索赔、被追责"为判据

好听不是首要判据，**安全可用**才是。以下为硬纪律，未满足不得声称可商用。

- **最安全的两条路径**：持"从训练阶段即获授权"的音乐/音效平台，或持正规曲库（商用授权、常含赔偿保障）——二者优于版权存疑的生成平台。商用必须走付费档，免费档不等于商用授权。
- **绝不未授权使用版权或热榜音乐作品牌内容**：平台会静音、限流或索赔；需用热榜声必须在平台内原生添加，且不适用于品牌商用主线。
- **纯 AI 音乐的版权局限**：无人类实质贡献的纯 AI 输出，在部分司法区可能不产生可主张的版权，亦难以阻止他人复用；需保留人类创作贡献的书面记录，不承诺"100% 安全"。
- **赔偿保障大多缺席**：多数生成平台不对输出相似性作赔偿承诺，选型时以"是否含赔偿条款"作为加分项，优选条款清晰者。
- **Content ID 仍会命中 AI 音频**：即使为 AI 生成，平台的内容指纹仍可能标记为相似并转走收益；成片发布需随片存档授权凭证与人类贡献记录，以备申诉。
- **AI 披露**：按平台与属地要求披露 AI 生成（如欧盟 AI 法案、平台自动披露机制）；广告与政务类内容必须显式披露。
- **署名与来源存档**：下载时即记录曲名、来源 URL 与授权页，归档至项目授权清单；批量下载后丢失元数据、事后无法反查视为流程缺陷。
