# Recut 全局导演技能：A-roll 语音取舍（recut-directing-a-roll）

本技能是 Recut 平台 App 无关的全局导演技能，**只回答一个问题：说话内容留哪些、删哪些**。适用范围为说话驱动的成片——单人口播、访谈、播客、课程等。以“观众该听到什么”为决策起点，先在可编辑文稿上完成语义取舍，再统一落回时间线。

## 边界声明

**本技能只管语音语义取舍；jump cut 的画面遮盖与 B-roll 归 recut-directing-b-roll；剪辑节奏归 recut-directing-editing。**

## 一、依赖顺序：先结构，后时序，后润色

- **当本次范围会新建或改变 A-roll 时，定稿前不叠加任何视觉/听觉润色层**（动效、字幕、音乐、B-roll 等）。上游结构一变，下游对齐全部重做；纯视觉或听觉的微调不触发未受影响的下游重做。
- 每一步单独与用户确认，不把多个结构检查点打包进一条回复。
- 口语剪辑不是轨道几何操作：先决定“保留/删除/重排什么话”，再决定如何执行。凡涉及说话内容的增删改，都在可编辑文稿上操作完成。

## 二、语义单元原则

- **按完整语义单元编辑**：以整句、整意、整答、整步为单位。不得为追求关键词匹配而截断半句。
- 任务点名保留时，严格裁剪到指定边界，只保留被点名的词句，不带入未要求的上下文；开放式清理时，保留完整单元，确保每段可独立成立。
- **不把不同重拍的碎片拼成一句人工话**：保留的句子必须来自一次完整的表达意图。
- **保留连接组织**：连接词、对比词、主语、宾语及与保留句相邻的必要词不是填充词，删除后会导致保留句不完整或突兀的，一律保留。
- 边界不确定时从保守：宁可保留或做更小的切口，也不做过度删除。
- 向用户解释时只描述内容本身（原话、短引述或平实转述），不暴露按转写分段定位的内部地址或编号。

## 三、口癖判断：三分类表

| 类别 | 典型例子 | 判断与处理 |
|---|---|---|
| 1 无语义气口 | 呃 / 额 / 嗯（无语义） / um / uh / er / ah | **安全删除**。不承载任何语义，可批量机械清理 |
| 2 语境相关填充 | 那个 / 就是 / 然后（无实质顺序时）/ so / like（无比较/强调时） | **看上下文人工判断**。若不承载顺序、延续、转折、因果、指代或强调，且删除后语感自然，则可删；否则保留。不确定则保留。此类永不进入机械批量清理 |
| 3 功能性连接与指代 | 所以 / 但是 / 对 / 嗯（承接） / 然后（有顺序） / like（作比较） / 这 / 那 | **保留**。承载逻辑关系或指代功能；`It works like a checklist` 的 `like`（比较）、`上传失败，所以我们重试了` 的 `所以`（因果）、`然后我们看第二点` 的 `然后`（顺序）均属此类 |

- 判定示例：`um, I think this solves it` 删 `um`；`It works like a checklist` 留 `like`。
- 机械批量清理仅适用于类别 1 的固定清单；类别 2 与 3 永远人工判断。

## 四、重拍与重复

1. **先确认是否真重拍**：多次尝试同一意图才算重拍。修辞强调、节奏性重复、结构标记、补充新信息的第二遍不算重拍。
2. **定义要保留的完整版本**：保留的版本可能包含前导引入、连接词、章节标记、主题设置、对比、限定词、宾语或结论——只要保留句依赖它们，就不是填充词。
3. **只删被完全覆盖的失败部分**：切点从失败或重复处起算，不自动回溯到更早的过渡或铺垫。
4. 多个完整版本通常取较后者（更接近最终意图），但不机械取最后；若后者缺少必要上下文，则保留更完整的版本，或为后者补上前者独有的前导信息。
5. 有用的铺垫（后续重拍未重复的）予以保留，从失败点开始切除。例如：`然后下一个跟喜剧不同。它在 Disney Plus 很火。叫…` + 重拍 `是部叫 Love Story 的 Disney Plus 热播剧`，保留前句，从失败点切除，衔接后句。

## 五、False Start 与残句

- 只删除**明显无信息量**的残句：已被完整版覆盖的放弃想法、只有悬挂短语、失败尝试的开头残留。
- 不删除：虽不完美但含有效信息的句子；为后文提供主语/宾语/上下文的前导；承担铺垫、对比、结论或情绪功能的句子。
- 局部损坏只删坏词、坏短语或坏停顿；若局部删除后不自然，则整段保留。

## 六、停顿压缩

- 0.8–1 秒以上的长停顿，压缩至约 0.3 秒。
- 句间保留 0.3–0.5 秒呼吸感；转折、强调或对比处可略长。
- 句内短呼吸属正常气息，不删除。
- **默认压缩而非置零**：口语需要自然呼吸，不把停顿完全抹掉。
- 用户给出明确阈值时按阈值执行（如“只处理大于 0.8 秒的停顿，至少保留 0.3 秒”）。
- 长停顿紧接失败重拍的，重拍删除时停顿随之删除。
- 停顿压缩仅作用于转写分段之间的段间停顿；句内呼吸需词级时间信息，当前不处理。

## 七、连接组织保护

- 连接词、对比词、主语、宾语、相邻源词不是填充词。删除前必须回读保留句是否仍通顺、逻辑是否完整。
- 重排完整语义单元后，需复查连接词（“所以/但是/然后/这/那/next”等）是否仍通顺，不通顺则补回或调整。

## 八、高光、重构、Hook 与目标稿对齐

- **高光提取**：先定标准（观点/结论/故事/情绪/冲突/教程步骤/数据点/主题）。每段必须自足，不带必要上下文的高光视为无效。按“信息密度 + 表达强度”取优，不按最短。
- **重构**：先确认目标结构（时间顺序/按主题/结论先行/教程步骤/短视频节奏），再移动完整语义单元，不把一句拆两半；移动后检查连接是否仍成立。
- **Hook / 短版本**：优先从原素材选取强主张、结果、冲突、反常识、提问或情绪点；需新生成 Hook 时先确认方向。短版本不按时长硬切，先定主线（问题/核心点/关键理由/结论），可删例子、重复或铺垫，但必须保住逻辑成立；时长与语义冲突时向用户说明取舍。
- **目标稿对齐**：目标稿是主约束。口语同义转述可接受，但不带入目标稿未要求的周边内容；多个相似版本取最完整、最自然、最贴合者；目标稿顺序不同则按目标稿重排，仍以完整语义单元为单位。

## 九、可编辑文稿工作流（介质中性）

1. 说话素材需先完成转写，转写是 A-roll 的可检索证据，非最终文案。转写分段只是技术切分，一句话、一个完整回答、一次重拍或一段连接可能跨多段，需在相邻分段中重建完整意思后再做取舍。
2. 将说话内容物化为可编辑文稿，在文稿上完成语义编辑：以行内标记对应词级音频删除，以整行删除对应整段不保留，以移动行对应语序重排，以停顿标记对应段间停顿压缩。
3. 机械清理仅用于固定无语义气口与批量压段间长停顿；语境相关词永不批量处理。
4. 定位时按转写分段定位并带时间戳回读；修正转写文本本身（如听写错词、说话人归属）不改变音频边界，与内容取舍的边界不互换。
5. 文稿编辑完成后统一落回时间线：删词或压停顿后保留区间被切成新的片段属正常结果，不是碎片化问题。每一步均可撤销。
6. 每次影响说话时序的变更后，重新读取文稿与时间线，检查是否出现逻辑断裂、上下文缺失、过度删除、顺序错误或停顿过紧/过松，并将依赖旧时序的视觉与字幕层标记为待更新。

## 十、确认门槛与保守原则

- **边界不确定时保守**：语义是否完整、是否为重拍、是否可删，不确定一律保留，或改用更小的切口。
- 复杂重构、激进缩短、生成式 Hook、多版本制作前，先确认目标长度、结构方向与保留原则；用户说“直接做”时可采用合理默认，但在结果中说明所采用的主线。
- 改后必须回读：检查逻辑断裂、上下文缺失、过度删除、遗漏清理、顺序错误、停顿过紧或过松，只修正明确问题，不扩大范围。
- 多版本/高光摘录在当前时间线内通过文稿编辑完成；独立版本需先复制项目再重新读取权威文稿，不通过零散时间戳手工拼片。

## 十一、与其它导演技能的分工

- 本技能只负责语音语义的“留与删”；不决定画面如何遮盖跳切。
- 画面遮盖、切镜与素材覆盖由 `recut-directing-b-roll` 负责；整体剪辑节奏、结构节拍与时长控制由 `recut-directing-editing` 负责。
