# Recut 全局生成提示词技能（references/generation-prompt）

本技能只回答：**一条交给图片/视频生成模型的生产级提示词怎么写？** 输入是镜头意图、资产与参考；**产物是一条可直接提交的提示词正文**，不是分镜、分析或标签。它是 `references/shot`（镜头意图）与各 App 方言之间的落格层，不写 provider 参数；镜头意图归 `shot`，故事/声音/平台/门禁各归其口，provider 参数（`modeType`/`ratio`）归各 App 适配层。

## 输出 Schema

恒定七段，顺序不可换、不得增删，段间空行：

```text
[CAMERA LOCK]   ≤1 行 / ≤30 字：焦段 + 景深 + 稳定 + 畸变呼吸（禁机身品牌，全片一套）
[STYLE LOCK]    ≤2 行 / ≤80 字：媒介 + 主光与影调 + 色调（禁引擎/渲染词堆叠，逐字复用）
参考锚定表       每条一行：role + 名称 + 一句细节（是什么/锚定什么/关键一致性特征）；正文必须内联引用
镜头基调         全段镜头纪律，≤1 行
声音设计         全片通用底声（一次）：环境底噪 + BGM 气质；不含逐镜内容
镜头序列         按 [起~止s] 逐镜写；每镜 1.5–4s、密切；主体/道具内联 {{参考图N}}；每镜旁白/对白与背景声随镜内联
[负面约束]       本片/本镜真实风险项，约 4–6 类
```

## 输入前置

1. **STYLE LOCK 来源**：世界取 `world.identity.style` / world.md（`worlds.get.skillMd`）视觉语言 + `references[]` 的 `style-ref`/`color-card`；否则取立项模板 `styleTemplate.visualPrompt` / `LIGHT_INVARIANT` / 导演风格文件。先冻结，**压缩到 ≤2 行 / ≤80 字**，不每镜重写。
2. **镜头意图**：世界取生产层 `scene.detail`（本场拍摄设计，提示词几乎全取自这里）；`shot.detail` 只作画面细节/预览参考。
3. **参考与角色**：世界先读 `references[]`——主角色 `character`（`character_reference`）、场景 `environment`、道具 `prop`、台词 `voice`（用了就必带、用该声线）；只有纯空场景可无参考。克隆/仿拍连真实锚点 `style-ref`/`motion-ref`。
   > 读法：`worlds.get`（world.md + facts + `references[]`）→ `worlds.production`（作品 → 脚本 → 场次；**镜头只作预览/测试参考**）；叙事/规格取 `script.detail` 与 meta。**生成依赖只有：资产 + script + scene**；分镜表（storyboard）不进生成。
4. **声音资产**：对白/旁白逐字、音色、环境/SFX。
5. **画幅与时长**由宿主传参、不写正文；片段长度按内容定，正文标 `[起~止s]`。

## 逐段规则

### [CAMERA LOCK] — 摄影机与镜头选型

**≤1 行 / ≤30 字**，只写：焦段 + 景深 + 稳定方式 + 畸变/呼吸。**禁机身/胶片品牌**（ARRI/Red/型号）与参数堆砌；`ratio/resolution/时长` 是适配层传参，不写这里。非写实媒介写等效光学与质感。全片一套、逐字复用。

### [STYLE LOCK]

**≤2 行 / ≤80 字**，只写：**媒介 + 主光与影调 + 色调**（例：`写实胶片颗粒，自然侧光，薄尘柔光晕，低饱和`）。**禁引擎/渲染词堆叠**（Unreal Engine / Octane / photorealistic 3D render / subsurface scattering / 8K 超写实）与泛化质量词；风格是本片创作意图，不是渲染器声明。逐字冻结、全片一致。

### 参考锚定表 — 参考锚点表达规则

用统一 `<reference id kind role label />` 标签。**每条参考必须写清细节——只写名字不够**（libtv 全靠这一层）：

- **每条 = role + 名称 + 一句细节**（这是什么 · 锚定什么 · 需要模型保持一致的关键特征），≤ 约 40 字，不复述剧情：
  - `参考图1（场景）川渝老小区夜晚屋顶：水泥电线杆 / 横贯主电线 / 绿门女儿墙 / 远处暖黄窗光——整场空间锚定`
  - `参考图2（角色）幺鸡：年轻麻雀、体型小巧、头顶羽毛微翘——主角身份与外观锚定`
  - `参考图3（角色）本地麻雀群：四只、分停电线/横担/天线——群像锚定`
  - `音频1（音色）幺鸡：十二岁清脆川渝少年声`
- **role 受控（生成链路不含 `storyboard`）**：`pov / color-card / environment / character / prop / style-ref / motion-ref / voice / sfx / music`；role↔kind 匹配，一图一 role，每个 role 只声明一次（后续用「同参考图N」复指）。本表是 AI 侧唯一权威，运行期镜像 `canvas-proposal.ts` 的 `PROPOSAL_ROLES` 必须同步。
- **表只做索引、绑定靠正文内联**：参考必须在镜头序列里**贴着实体出现**——`牛霸 {{参考图2}} 大步向前`、`断斧 {{参考图5}} 拄地`；只在表里挂名、正文不引用＝模型收不到绑定。
- **正文用 id、提交用别名**：正文 `<reference id…>`；提交时改写为「组内编号 + role 短标签 + 名称」，如 `参考图4（角色）「小荷」` / `音频1（音色）「随园先生」`；id 不进模型串。
- **对应关系只有位置**：provider 只收到一个有序数组（`reference_images:[图1,图2,…]`），没有逐图名称。`参考图N` = 提交数组第 N 项——**提交顺序 = 声明顺序**，编号写定后不得再增删/重排参考。
- 只引用本片段真实需要的参考；正文每个 token 必须有真实绑定，未绑定即拒。
- **分镜表不是生成参考**：storyboard 只作排产/预览（`references/plan` / `references/shot`），不提交给视频模型。

### 镜头基调

声明一次：允许的机位与运动、轴线与主体屏幕位置、**一镜一主导运动**、禁止无意义漂移；复合运动写清阶段顺序。

### 声音设计

**只写全片通用的底声层，一次声明、不因切镜重置**：持续环境底声（如更漏、隔墙人语、市井底噪）+ 有无 BGM 与气质。**不写任何逐镜/逐场的旁白、对白或局部声**——那些属于「镜头序列」，随镜内联，不在此处索引或转指。

### 镜头序列

每镜一行：`[起~止s] 功能=… ｜ 信息变化=…`（这两个是给作者/自检的标签，**不输出给模型**）→ **景别/机位 → 一个主导运镜（方向/速度/落点）→ 动作起止 → 可见面 → 该镜声音**。功能取建立/关系/揭示/反应/插入/主观/转场/hook 等；区间连续相接、无空档、总和即片长；段内标 HARD CUT，每镜结束状态 = 下一镜起始状态。

- **一镜一信息**：一个动作 + 一个信息变化；写清运镜起点/终点与屏上内容；高风险镜先拆分。
- **逐镜声音（内联本镜）**：每镜写自己的 ① 旁白/对白——逐字、标时间、引号标注、不改写（有台词必带 `role="voice"`）；② 背景声/局部环境声——随场景改写、按因果（接触/受力/声源在前）、对齐区间。底声已由「声音设计」声明一次，此处不再重复、也不转指。
- **可见面与画内文字**：每个可见面写清上面是什么；要观众读到的字逐字写死（引号、≤15 字、给位置、载体够大、标时间），不要读才用无字编码并声明无可读文字。
- **表演（情绪只能外化）**：禁心理/文学词（恐惧、悲伤、压迫感、电影感）；转成可观察信号——视线/眨眼/嘴角/下颌/呼吸/手指/重心/步态/停顿/衣料与汗。例：`他很害怕` → `脚步停住、重心移到后脚、视线转向门口、嘴唇微张、胸口两次短促起伏`。
- **物理与动作**：接触先于位移、受力先于反应、光源先于反光、动作先于环境反馈；力按传递写、二级运动派生回落；一个镜头一个主要动作、保清晰轮廓与方向，复杂动作拆镜，接触点用插入镜；动作镜按 `起势→位移→接触/落空→反应→定格` 写（`references/story` 动作账本）。
- **朝向与连续**：载体朝向 = 持握 + 视线（看手机却让屏正对镜头＝方向反了），拍屏/页内容就换机位（近特写/过肩俯拍）；跨镜保视线匹配、屏幕方向、主光方向与人物左右关系（世界坐标一致）。
- **密切 + 内联**：以 **1.5–4s 为主密切**（不做整段单一长缓推）；每镜给 景别/机位/运动 + 具体动作/微表情 + **前景/纵深/环境物理**；主体、道具**首次出现即内联 `{{参考图N}}`**（角色转面图就点具体视图，如「取 参考图4（角色）的正视图」）。
- **一段多镜**：一次请求可含多镜连续段（HARD CUT 相接），长度由内容定、不机械切片；跨镜同一世界状态、不重建房间。

### [负面约束]

具体对象 4–6 类（不用类别）；通用：水印/角标/图标/时间/无关 UI；**「无文字/无字幕」仅在不需要可读画内文字时写**，要了可读文字就改成文字质量项（无乱码/错别字/重复/溢出）。

## 总规则

### Criticality：视觉风险预算（内部决策，编译进画面，不外露标签）

- **1 个 PRIMARY EXTREME**（构图/透视/纵深/尺度差/运镜/速度/调度/遮挡/负空间/焦段压缩/空间密度/表演/静止/光影反差/环境动态 选一）+ ≤1–2 支撑，其余维度主动压低。
- **强度停在 EDGE**（近失效但可读），不进 COLLAPSE（破坏识别/结构/因果/连续性）。
- **极端必须物理化**：用空间/速度/尺度/遮挡/视差/物理反馈，不用 `extreme/dramatic/epic`。
- **至少 1 个视觉锚点**（脸/眼/手/道具/运动方向/高亮/剪影/消失点/出口）；越界只局部退让。
- 不得覆盖剧情/身份/资产/轴线/因果/End State/Hard Lock。

### 真实感与去 AI 味（Anti-AI：把画面写「脏」、写「有镜头」）

**目标：让画面像被一台真实摄影机偶然拍到的，而不是被渲染出来的。** 每镜至少落 **2 项**；写进该镜的「画面构图」里，不放在全局 STYLE LOCK。

| 技巧 | 怎么写（写进每镜） | 作用 |
|---|---|---|
| **前景遮挡 / 虚化** | `镜头前方 <物>（枝叶/门框/路人肩背/雨雪/发丝/烟）成虚化前景，占画面 <一角/下部>` | 最强去 AI 味：纵深 + 观看感 |
| **浅景深 + 焦点** | `极浅景深，焦点在 <主体>，前后景分离`；必要时 `焦点从 A 轻移到 B` | 分离主体、避免"全景均焦" |
| **介质/大气** | `空气中有浮尘/水汽/烟/细雪/热浪`、`体积光`、`轻微 lens flare / bloom` | 空气感、非 CG 干净 |
| **实拍镜头效应** | `轻微手持呼吸、镜头呼吸、轻微滚转/色差、胶片颗粒、克制暗角`（**幅度克制到几乎察觉不到**） | 摄影机在场证据 |
| **有动机的不均匀光** | `窗/灯/火/屏作实用光源，强光比、遮挡阴影、明暗过渡不完美` | 去掉平光塑料感 |
| **材质与瑕疵** | `皮肤毛孔/汗/油光、织物磨损起球、金属划痕、灰尘/指纹/边缘磨损` | 去掉光洁 CG 表面 |
| **非完美构图/表演** | `主体略偏离中心、留真实负空间、动作有起势与惯性、视线不总对镜头` | 去掉"摆拍/完美对称" |
| **景深分层运动** | `前景动（虚）、主体稳、背景动`（视差） | 真实空间感 |

**Anti-AI 黑名单（出现即重写）**：过光滑/塑料皮肤/磨皮无毛孔；过饱和/HDR/全域均匀亮/无阴影；完美对称居中、正面平光；整镜全焦无前景；泛化美词（电影感/大片感/氛围感/超写实/8K）；引擎/渲染词（UE5/Octane）；整段匀速缓推无切；主体悬浮无环境物理；材质/服饰完美无瑕。

**注意**：真实感来自**具体物**（虚化的前景是什么、光从哪来、哪里有尘），不来自"更真实/更电影"这类形容词；别把技巧堆成新的关键词，每镜挑 2 项落到实物上。

### 提交自检

- [ ] [CAMERA LOCK] ≤1 行（无机身品牌）/ [STYLE LOCK] ≤2 行（无引擎词）且逐字复用
- [ ] 参考 role↔kind 匹配、真实绑定；**每条都有一句细节描述**；正文 token **内联在实体上**并与 `referenceIds` 同序；世界含主角色必有 `character`
- [ ] 分镜表（storyboard）未进生成参考；角色转面图只取需要的视图
- [ ] 区间连续、总和=片长；每镜一信息/一起止/一主导运动；**密切**、HARD CUT 已标
- [ ] 每个可见面有内容；每镜有前景/纵深/环境物理；文字判支正确；因果顺序与载体朝向自洽
- [ ] 每镜至少 2 项真实感（前景虚化/介质/实拍效应/瑕疵/动机光），且未命中 Anti-AI 黑名单
- [ ] 每镜都有旁白/对白与背景声；底声声明一次
- [ ] 正文不含 `ratio/resolution/时长/modeType`、类别式负面词、空泛质量词、引擎/渲染词；Criticality 标签未进提交串
