# 读法：整片 ↔ 细节互证

读参考不是「看一遍」，而是**带着问题在整片与细节之间来回看**，直到能解释「它为什么有效」。目标产物是：可复用、可定位、可被下游（clone/remix）使用的理解。

## 1. 先整片，再细节，再回到整片

1. **整片通读**：从开场到结尾看一遍，形成初步判断——钩子怎么抓人、论证/故事怎么推进、哪里是兑现点、结尾怎么收。
2. **细节取证**：用 `contactSheet`（带时间码）与 `frames` 找到关键画面；有转写时对齐台词与画面变化。
3. **回到整片**：用细节修正或推翻初步判断，写下「它为什么有效」的解释。

片段位置以**源片时间**为准。

## 2. 取样密度随问题变化

- **看全局**：区间宽、间隔大（如每 1s 一帧），用于理解论证/结构。
- **看一次变化**：区间窄、间隔小（如 0.1s），用于追踪一个入场、切换或揭示。
- **看字与细节**：放大单帧尺寸，用于读排版、品牌、字幕样式。
- 长片分段读，但始终保留整片线索。

一次变化可能落在两个采样点之间——**不要只用「几个代表帧」冒充时间线**；沿台词与画面系统把变化过程读出来。

## 3. 用台词定位画面变化（有转写时）

- 用段落级转写（默认）就能理解内容；把台词的分句与画面切换并排看，找「哪句话带来哪个画面/图形」。
- `contactSheet` 传 `transcriptAssetId` 可把词标签叠在帧下，读「词 ↔ 画面」更直接。
- 词级时间（`recut.media.words`）**默认不开**；只有当「必须把某个图形/音效精确对到某个词」时才开。

## 4. 证据命名与归档

- 证据（帧/接触表/片段）都是**普通素材**；要用就在 `content` 里 `<media assetid="…">` @ 它，或作为一条 `media` 属性。命名要能让人一眼回到当时的疑问（如 `opening-hook-0-3s`）。
- 一个「系统」的记录：把「同一套东西的多次出现」记成一次描述 + 各次的时间，而不是每次重复描述。
- 读出的**事实**与你的**解释**都写 `content`/`attributes`；引用证据用 `assetId`。

## 5. 什么时候算「读懂了」

能同时回答：

- 这段片子**想让观众感到/学到/决定什么**？
- 它用**哪些视觉/声音系统**、在**哪些时间点**、**响应哪句话/哪个动作**做到这一点？
- 如果换主体/产品/语言，**哪些关系必须保留、哪些表面可以换**（判据交给 `recut-director（references/remix）`）？

回答不了就回到对应时间点重看；不要用泛泛的形容词补空白。
