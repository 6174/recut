# 阿墨的墨色日常

## 核心定位

为网站配图、产品介绍与功能演示视频生成风格一致的单色版画风网页插画。主角是「阿墨」：乱发丸子头的松弛系青年，标配一杯冒热气的咖啡，置身**奶油纸底 + 黑墨丝网版画质感**的世界。

## 核心视觉语言

- 奶油米黄纸底，全图只有「黑墨 + 纸底」两阶；灰色只以 halftone 网点出现。
- 保留印刷颗粒、露白、轻微套印偏移；线条粗犷松弛。
- 大块黑色波浪蒸汽墨云是品牌记忆点；星星、小花、螺旋线是点缀符号。

## 版式双模式

- **模式 A 贴纸涂鸦**：手绘涂鸦感 + 手写短句落款 → 社媒配图、彩蛋、情绪卡片。
- **模式 B 海报版式**：气泡体大标题 + 干净细线插画 + 底部信息栏 → hero 图、产品视频关键帧、Banner。

先读 `references/layout-modes.md` 判断用哪种。

## 工作流（配图/视频生产）

### 1. 消化选题

判断用途与模式（A/B）；提炼一件「日常小事」，套三拍微结构。

### 2. 出 shot list

每镜头写清：场景、模式与版式密度、阿墨的情绪状态（查九宫格表）、道具与蒸汽、点缀符号、文字内容。

### 3. 生成关键帧

- 涉及阿墨的每一帧，必须把角色设定九宫格作为参考图传入。
- 配图/视频关键帧 16:9 或 1:1；设定/表情九宫格 1:1；每张单独生成。

### 4. 检查

两阶 + 网点灰？蒸汽墨云在？瞳孔/衣纹/指节没偷跑？四周留白？不合格优先重生成。

### 5. 交给视频生成

关键帧 + 微动作提示（蒸汽上升、星星炸开、眨眼、键盘敲击）生成视频片段；BGM 用 lo-fi 或轻爵士鼓组，音效只用抿咖啡、键盘、纸张摩擦这类小物件声。

## 资源口径

- `assets/character-sheet.png`（primary）：一致性锚点，必须随参考图传入。
- `examples/` 的成品范例：定义氛围密度与版式层级，**不复刻构图与命题**。
- 角色外形以「阿墨」实体（含 body 全文）为准；风格以「风格 DNA」与规则实体为准。
