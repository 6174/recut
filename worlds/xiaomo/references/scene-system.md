# 场景体系：墨咖啡工作室与网页画布

「墨咖啡工作室」是全员共用的舞台——一张放大的工作台，偶尔延伸到屏幕里的网页画布。群像场景以工作台横线为共同地平线，每个角色有固定的功能位（见 xiaomo-ip.md 关系图）。

## 场景清单

1. **咖啡角**：书桌一角，马克杯 + 手冲壶 + 蒸汽墨云；最常出场。
2. **屏幕前**：笔记本电脑/显示器，阿墨的黑色剪影背对屏幕光；屏幕内容用网点灰表示。
3. **便签墙**：贴满歪斜便签的墙面，阿墨站在梯子上贴/撕。
4. **绿植角落**：显示器后面一盆龇牙咧嘴的大叶绿植，叶子用黑墨剪影。
5. **深夜加班**：整幅画面压成深灰纸底，只有台灯一圈纸色光斑。
6. **部署成功**：屏幕弹出打勾对话框，星星与十字星炸开。

## 场景公式

一个日常物件 + 一块网点灰背景 + 一组点缀符号：
- 背景大块面用网点灰 halftone，绝不平涂灰。
- 蒸汽、星星、螺旋线只出现在主体周围，不铺满画面。
- 桌面横线/地平线是一条松弛的单线，允许两端飞出。

## 组合场景清单（群像）

1. **发布日**：豆豆指屏幕（感叹号）+ 阿墨淡定敲键盘（蒸汽）+ 小点撒星星 + 炭炭尾巴卷鼠标线。
2. **断网之夜**：炭炭睡在路由器上（Z 字）是断网原因；小点举问号，豆豆急转圈，阿墨抿咖啡。
3. **手冲事故**：小点打翻手冲壶，蒸汽墨云变成一团乱云；炭炭跳开；阿墨递纸巾。
4. **全员摸鱼**：四个角色各看各的方向，头顶各一个松弛符号；适合周末氛围图。

## 产品化场景（用于产品介绍）

- Hero 图：全员或阿墨单人 + 大蒸汽墨云 + 手写短句（模式 A）或 大标题 + 倒咖啡（模式 B）。
- 功能演示：豆豆把一个巨大按钮/开关/滑块当道具推拉，阿墨在旁 OK。
- 对比图：左「混乱的一天」（豆豆+乱线）vs 右「用完之后」（阿墨+清爽留白）。
- 新手引导：小点提问（问号）→ 阿墨/产品回答（OK + 对勾）。
