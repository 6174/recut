# 场景体系：墨咖啡工作室（合伙办公室）

一间改造的旧铺面办公室：吧台兼会议室，长桌是主战场，白板贴满需求便签与数据图表，角落是机房。群像以长桌横线为共同地平线，每个合伙人一个职能位。

## 职能位地图

```
[吧台咖啡角]   [设计工位]   [白板墙]   [机房角落]
  阿墨           茉茉         豆豆       小点 + 炭炭
```

## 单人/双人场景清单

1. **吧台咖啡角**：阿墨的主场，手冲壶、马克杯、蒸汽墨云；谈客户也在这里。
2. **设计工位**：茉茉的数位板 + 日式茶杯，桌上一支画笔筒；安静得能听见笔尖。
3. **白板墙**：豆豆的战场——需求便签、数据曲线、热点日历；他经常对着白板原地转圈。
4. **机房角落**：路由器、缠绕的网线、炭炭的睡窝；小点蹲着修东西的固定机位。
5. **深夜办公室**：画面压成深灰纸底，一盏台灯一圈纸色光斑，配一台亮着的笔记本。

## 群像组合场景（对应单元剧情）

1. **改稿八版**：豆豆举着便签墙前倾咆哮（感叹号），茉茉稳坐数位板前（小花），阿墨吧台喝咖啡（蒸汽墨云），小点抱电脑围观（问号）。
2. **热点半夜爆**：深灰底 + 台灯光斑，豆豆举手机炸毛，阿墨披围裙敲字，小点抱着电脑待命，炭炭继续睡。
3. **服务器之夜**：机房特写，炭炭睡压路由器（Z z z），小点蹲着接线（问号变对勾），豆豆在身后鞠躬。
4. **交付日**：全员围着一块屏幕看进度条，发布成功星星炸开，只有阿墨还端着杯子比 OK。

## 产品化场景（用于产品介绍）

- Hero 图：全员或阿墨单人 + 大蒸汽墨云 + 手写短句（模式 A）或 大标题 + 办公室一角（模式 B）。
- 功能演示：豆豆把巨大按钮/仪表盘当道具操作，阿墨在旁 OK。
- 对比图：左「改稿第八版」乱线便签雪崩 vs 右「用对工具」清爽留白 + 一条上扬曲线。
- 新手引导：小点提问（问号）→ 阿墨/产品回答（OK + 对勾）。

## 场景公式

一个职能位道具 + 一块喷点/网点灰背景 + 一组点缀符号：
- 背景大块面用喷点灰晕或网点 halftone，绝不平涂灰。
- 蒸汽、星星、螺旋线只出现在主体周围，不铺满画面。
- 桌面横线是一条松弛的单线，允许两端飞出。
