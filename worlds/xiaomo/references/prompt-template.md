# 提示词模板

## 通用底料（所有模式共用）

> 手绘单色丝网版画风网页插画，奶油米黄纸底 #F0E4C8 带纸张噪点与纤维感，全部图形只用炭黑油墨与纸底两阶表达，灰色仅以 halftone 网点/喷点渐层出现。笔触是关键：蜡笔/软炭笔在糙纸上的摩擦痕迹，线条由多段短笔触叠成、接头有深浅重叠，大面积黑色用来回涂抹的排线与打圈笔触填出并保留露白点，偶尔溢出轮廓像涂出界；人物身后有细密喷点灰晕把人物托出纸底。人物是**成人化变形**：拉长身形、细长脖子、有力的长鼻子、粗一字眉、眯眼、浓密夸张的黑色大形发型——宁做爵士乐手，不做 Q 版娃娃；禁止大圆眼、腮红、婴儿比例、矢量匀线。画面四周留纸色边框，像一张扫描进电脑的手绘印刷卡片。

## 角色底料（按出场角色拼接）

- 阿墨：夸张蓬乱黑色高丸子头（碎发飞出）、络腮胡茬细点笔触、波浪眯眼「w」弧线、深色圆领卫衣 + 咖啡师帆布围裙（胸袋插咖啡勺）、肩宽体厚站姿放松；端超大咖啡杯（蒸汽墨云）或比 OK。
- 茉茉：低马尾 + 发簪（簪尾圆球）、斜刘海、细长上挑眯眼、小圆点耳环、黑色高领毛衣；捧日式茶杯（细蒸汽）+ 画笔。
- 豆豆：油亮背头（一撮翘起）、圆框眼镜、眉心八字锁、细竖纹衬衫 + 深色针织背心、体态前倾像随时要冲；叉腰举粗笔感叹号。
- 小点：服帖直发锅盖头（耳旁翘两撮）、全员唯一圆点眼、polo 领工装背心（口袋插铅笔）、瘦高；抱旧笔记本电脑或蹲着插网线，头顶大问号。
- 炭炭：敦实纯黑剪影猫、大圆头小三角耳、粗尾末端卷成螺旋卷、眯眯眼「w」猫嘴。

## 生成纪律

- 每张单独生成，不拼图（IP-system 总图与九宫格除外）。
- 多人同图时，把 `assets/ip-system.png` 作为参考图传入，检查四人发型笔触是否可区分。
- 检查：笔触是否有飞白断墨与涂抹感？蒸汽墨云在？瞳孔/衣纹/指节没偷跑？不合格重生成。
