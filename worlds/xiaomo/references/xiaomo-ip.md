# 墨咖角色体系（IP System）

阿墨不是一个人在战斗——整个 IP 围绕一间「墨咖啡工作室」展开，角色按功能互补，一张 IP-system 总图可以一次性产出全部角色。

## 角色阵容

### 阿墨（主角 · 松弛担当）

- **外形**：乱翘黑色丸子头（发丝飞出）、大圆脸眯眯眼「w」弧线、整块黑色剪影身躯、纸底色圆润大手。
- **人设**：主理人，什么都难不倒他，先喝口咖啡再说。
- **功能位**：产品主讲人、hero 图主角、三拍叙事的「喝一口」节拍。

### 炭炭（黑猫 · 气氛担当）

- **外形**：一团黑色椭圆剪影猫，通体涂抹笔触，仅一双眯眯眼和一条竖起的粗尾巴是纸底色；耳朵两个小三角。
- **人设**：工作室的猫，踩键盘、睡在路由器上、尾巴总是第一时间表达情绪。
- **功能位**：彩蛋、转场、吉祥物；不占主构图时可以只露一条尾巴。

### 豆豆（搭档 · 活力担当）

- **外形**：短卷发（打圈笔触卷毛）、圆框眼镜两个圈、斑马纹横条衣（网点灰条纹）、永远比阿墨多一个感叹号符号。
- **人设**：充满干劲的搭档，deadline 前跑得最快，负责把阿墨拽回现实。
- **功能位**：对比关系（焦虑 vs 松弛）、功能演示里的操作者、冲突发起者。

### 小点（实习生 · 萌新担当）

- **外形**：最小的一个，圆寸头（密点笔触）、脸上的腮红是两个网点灰圆、 oversized 黑色卫衣只露出两只圆手。
- **人设**：什么都不懂但什么都想试，打翻过三次手冲壶。
- **功能位**：新手视角提问者（「这是什么？」）、错误示范担当、被炭炭治愈的对象。

## 关系图

```
阿墨（松弛） ←→ 豆豆（着急）    对比喜剧轴
小点（萌新） ←→ 炭炭（猫）      治愈彩蛋轴
四人都围着同一张工作台
```

## 组合规则

- **单人**：hero 图、情绪特写（用对应角色的符号：阿墨=蒸汽墨云、豆豆=感叹号、小点=问号、炭炭=尾巴+Z 字）。
- **双人**：阿墨+豆豆（讲产品对比/协作）、小点+炭炭（萌系彩蛋）。
- **全员**：工作室群像、周年海报、产品发布；以工作台横线为共同地平线。
- 每个角色必须保持各自的发型笔触语言（丸子头乱笔触/打圈卷毛/密点寸头/涂抹猫团），这是多人同图时区分角色的关键。

## 一致性红线

- 永远不画瞳孔、不画衣纹、不画手指节。
- 全员共用同一墨色与同一纸底色；角色区分只靠轮廓与发型笔触。
- 炭炭永远是纯黑团，不给它白斑花纹。
