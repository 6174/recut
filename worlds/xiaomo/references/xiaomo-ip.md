# 墨咖团队手册（IP System）

「墨咖啡工作室」是一个**一起工作的团队**，不是一家人：四名不同来历的同事 + 一只猫，各有轮廓语言，一张图可以全员产出。

## 造型总纲

- **比例（中间态）**：头身比 1:2.5~1:3 的年轻职场感——禁止 Q 版婴儿比例，也禁止拉长爵士身材；禁止腮红。
- **脸**：波浪眯眼、短弧线小鼻、粗短眉；瞳孔全员不画（小点是唯一例外，圆点眼）。
- **发型即身份证**：发型轮廓语言严格区分，是多人同图时辨认角色的第一依据。
- **手**：块面化圆润，不画指节。
- **质感**：人物身后一圈喷点 halftone 灰晕托出纸底；黑色大形内保留涂抹排线露白。

## 人物小传

- **阿墨**：主理人。deadline 和 bug 都难不倒他——先喝口咖啡再说；「都行，问题不大」。
- **茉茉**：平面设计师，阿墨多年好友。安静笃定，茶比咖啡稳；少言，一句「茶还挺稳」就是她的高光。
- **豆豆**：运营搭档。风风火火爱喊 deadline，负责把阿墨拽回现实，也负责发起所有冲突。
- **小点**：实习生。天真勤快，锅盖头下藏着「i can fix it」的热情，打翻过三次手冲壶。
- **炭炭**：工作室的猫。睡在路由器上，兼职一切小事故的元凶，也是所有人的疗愈时刻。

## 关系与组合

```
阿墨（松弛） ←→ 豆豆（着急）    对比喜剧轴
茉茉（定力） ←→ 小点（慌张）    师徒带教轴
炭炭横跨所有人                治愈彩蛋轴
```

- 单人 hero：配各自专属符号；双人：阿墨+豆豆（协作对比）、茉茉+小点（带教）、任何人+炭炭（彩蛋）。
- 全员群像：各占一个工位功能位（阿墨喝咖啡敲键盘、茉茉画数位板、豆豆指便签、小点蹲着插网线、炭炭睡路由器），工作台横线为共同地平线。

## 一致性红线

- 头身比 1:2.5~1:3；禁止婴儿比例与拉长身材。
- 发型轮廓 + 专属符号双保险辨认角色；瞳孔仅小点可画圆点。
- 黑发黑衣同一墨色，手脸同一纸底色；炭炭纯黑无花纹。
- 生成时必须传对应角色 assets/ 设定图作参考，不许只靠 prompt。
