# 版式双模式：贴纸涂鸦 vs 海报版式

阿墨的产出分两种模式，接到任务先判断用哪种。

## 模式 A：贴纸涂鸦模式（scribble sticker）

- 纯手绘涂鸦感：粗犷黑线 + 涂抹质感填充 + 网点灰条纹。
- 蒸汽大墨块、星星、小花等点缀符号丰富。
- 文字只作配角：底部两行松弛的手写短句（铅笔随手写感，小字号）。
- 用途：社交媒体配图、贴纸、彩蛋插图、情绪卡片。

## 模式 B：海报版式模式（type poster）

- 文字是主角之一：顶部粗壮的气泡体/胖显示字体大标题（黑色实心、圆润带高光缺口），标题下一行小字副标（如 "COFFEE" / "SINCE 2024" 分列左右）。
- 插画居中：**线条变细变干净**（与模式 A 相比少涂抹、少颗粒），人物动作安静专注（倒咖啡、打字、看屏幕），无点缀符号或少量点缀。
- 底部信息栏：一行特粗大写标语（如 "ENJOY COFFEE TIME"）+ 两三行小号大写说明文 + 左右分列的落款（@handle 与联系方式）。
- 用途：网站 hero 图、产品介绍视频关键帧、海报、Banner。

## 选择规则

- 给视频做关键帧/网页大图 → 模式 B（信息层级清晰，标题区可替换为产品文案）。
- 做氛围点缀、转场、彩蛋 → 模式 A。
- 两种模式必须共用同一角色外形与纸底墨色，只是线条精致度与版式密度不同。
