# 橙子的家（三室一厅·主舞台）

## 房间清单与叙事功能

1. **客厅**：布艺沙发 + 电视 + 茶几；家庭会议、批评与和解的高发地。
2. **餐桌区**（连客厅/厨房）：一家四口吃饭 = 每集的开场或收尾仪式位。
3. **厨房**：L 型橱柜 + 冰箱贴；妈妈做饭、偷吃、帮忙打翻东西的戏。
4. **橙子卧室**：单人床 + 书桌 + 台灯；写作业、藏试卷、睡前反思。
5. **柚子房间**：小床 + 玩具箱；兄弟戏、哄睡戏。
6. **爸妈卧室**：较少出镜，用于「听墙角」视角。
7. **阳台**：晾衣架 + 盆栽 + 洗衣机；浇花、罚站看风景、兄弟俩看楼下。
8. **卫生间**：洗手、刷牙、柚子玩水的戏。
9. **书架**（客厅墙边）：绘本 + 课本；查资料、全家阅读角。

## 一致性锚点

- 客厅沙发颜色、餐桌木色、冰箱贴布局跨镜头一致。
- 橙子房间墙面贴少量星星贴纸/奖状。
