# 小灰哥 IP

## 角色定义

小灰哥是思考、情绪、认知类内容的固定视觉主角。他不是吉祥物，而是读者的镜子：一个独居的普通都市年轻人，安静、内耗、敏感、想太多，但始终温柔。

默认每张漫画都出现小灰哥。他必须承担画面的情绪与动作主体，不能只是站桩。

## 外形

- 圆头白色小人，头是光滑的圆，没有发型。
- 小点眼，默认状态是疲惫的死鱼眼。
- 深灰色 oversized 连帽卫衣 + 宽松深色长裤。
- 永远挂着白色有线耳机，耳机线连到口袋里的手机——耳机线是他的生命线，是与世界保持距离的连接方式。
- 线条粗、轻微抖动、手绘感；几乎全灰，唯一的纯白元素是耳机线。

## 性格

- 安静、丧而温柔；不卖惨、不鸡汤。
- 内耗但自我觉察，正在慢慢想明白一些事。
- 自嘲式冷幽默。
- 独居，有自己的两室一厅和一只柯基（馒头）。
- 女朋友小暖偶尔来，是他情绪系统里的外部变量。

## 核心视觉语言（必须遵守）

- **思想泡泡 = 内心可视化**：他的内心活动全部画在头顶的思想泡泡里。
- **乱线团 = 情绪噪音/内耗**：焦虑、反刍、想太多都画成缠乱的黑色涂鸦线。
- **从乱到清 = 认知转变**：思考类主题用「乱线 → 逐渐解开 → 一个简单的圆/灯泡」表达洞见。
- **唯一亮色 = 洞见/希望**：全灰画面里只允许一处微小的暖色（灯泡光、远处一扇亮窗）。

## 常见状态库

- 躺床上戴耳机盯天花板，头顶乱线团。
- 趴在桌上装死。
- 深夜街头/末班地铁里放空。
- 盘腿坐地，思想泡泡从乱线解成灯泡。
- 深夜开冰箱门发呆。
- 被馒头默默陪着。
- 被小暖轻拍、投喂、念叨。

## 禁止

- 不要画成可爱吉祥物、贴纸、儿童卡通。
- 不要给小灰哥加头发、加表情包式夸张五官。
- 不要鸡汤大字、励志海报感。
- 不要让画面变成商业插画或精致动漫画风。
- 不要让小灰哥只是站桩背景板。

## 判断标准

去掉思想泡泡或乱线团后，如果画面失去了「内心戏」，说明这张图没有抓住 IP 的核心语言。
