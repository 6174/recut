# 生成后检查（QA Checklist）

## 必过项

- [ ] 画幅正确：单幅 3:4 / 九宫格 1:1 / 全景 16:9；内容图没有多张拼接。
- [ ] 扁平纯灰背景；无纸纹、渐变、阴影、噪点、毛绒质感。
- [ ] 黑色粗手绘线，轻微抖动；角色灰阶只有 2-3 档。
- [ ] 小灰哥形象与角色设定集一致：圆头无发、死鱼眼、深灰卫衣、白耳机线。
- [ ] 至少一种内心可视化语言：思想泡泡 / 乱线团 / 解线过程。
- [ ] 亮色规则：全灰 或 仅一处微小暖色且服务洞见/希望/温度。
- [ ] 配角（小暖/馒头）线条语言与主角统一，无动漫画偏差。
- [ ] 文字纪律：最多一句手写中文短句（10 字内为佳）作为 caption，位置固定（画面上沿或下沿），无错字、无标注、无边框分格；不用文字也能成立的图优先不用。

## 常见问题 → 处理

| 问题 | 处理 |
| --- | --- |
| 小灰哥长出头发/五官变精致 | 重生成，强化「exactly as the reference」锚定 |
| 画面变成可爱吉祥物/贴纸风 | 重生成，加 not cute-mascot, not kawaii, deadpan |
| 柯基毛绒绒、有厚重阴影 | 重生成，强调 flat simple line vocabulary, no fur texture |
| 没有内心戏，纯场景站桩 | 重写提示词，把命题转成思想泡泡/乱线团的可视化 |
| 出现鸡汤大字或标题 | 重生成，no text, no labels |
| 背景出现渐变/纸纹/暖色调 | 重生成，强调 flat solid gray background, no gradient |
| 配角抢戏 | 删配角或缩小为「陪坐/远端」级别存在感 |
| 九宫格各格形象不一致 | 重生成，逐格重申同一角色描述 |

## 迭代口径

- 太甜/太治愈 → 收回结尾，让解开程度变小；亮色删掉。
- 太惨/太压抑 → 加一个微小外力（馒头、一扇亮窗），或让乱线松开一角。
- 太满 → 删道具，留一个场景锚点物件（泡面杯/耳机线/晾衣架）。
- 太像旧图 → 保留命题，换场景与身体姿态。
