# 风格 DNA

## 一句话

扁平灰底、黑色粗手绘线、极简灰阶、思想泡泡与乱线团；丧但干净，安静但准确——像深夜一个人在平板上随手画给自己的情绪速写。

## 必须

- 扁平纯灰背景：单一灰度铺满，无纸纹、无渐变、无阴影、无噪点。
- 黑色粗手绘线稿：线宽均匀偏粗、轻微抖动、不机械、不矢量。
- 角色扁平灰阶填充：深灰卫衣、浅灰皮肤、白色耳机线；只有 2-3 档灰度。
- 一张图只讲一个情绪瞬间或一个认知动作。
- 内心戏必画：思想泡泡 / 乱线团 / 解线过程，三选一起码一个。
- 角色线条语言全宇宙统一：小灰哥、小暖、馒头必须在同一张「手」下画出来。

## 颜色

- 全图灰阶 + 黑白。
- 唯一允许的彩色：一处微小暖色（暖黄灯泡光、远处一扇亮窗、一点烛光）。
- 亮色只出现在「洞见 / 希望 / 温度」的时刻，一张图最多一处；情绪图通常干脆全灰。

## 产出形式

- 单幅情绪漫画：3:4 竖版。
- 角色设定 / 表情集 / 姿态集 / 配角集：1:1 九宫格（3x3，不画面板边框，靠留白分格）。
- 公寓全景等空间图：16:9 横版。
- 每张单独生成，不把多张内容图拼在一张里。

## 绝对不要

- 不要可爱吉祥物海报、儿童卡通。
- 不要日系动漫画风、精致阴影、厚涂、渐变光效。
- 不要毛绒质感（柯基也是扁平的）。
- 不要鸡汤励志大字、成功学海报感。
- 不要真实 App 截图、复杂背景细节。
- 不要给小灰哥加头发或夸张五官。

## 参考图口径

`examples/` 里的设定集与九宫格是**角色一致性的权威锚点**（低频校准：头型、五官密度、线条粗细、灰度档位）；单幅范式图（乱线团/解线灯泡）定义单张内容图的情绪密度。不照抄构图，不复刻案例里的具体命题。
