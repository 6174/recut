# 小灰哥情绪漫画（pgc.xiaohuige）

> 为中文思考、情绪、认知类内容生成灰阶涂鸦漫画。
>
> 小灰哥 IP | 女友小暖 | 柯基馒头 | 两室一厅场景体系 | 思想泡泡×乱线团×唯一亮色 | 全灰阶扁平涂鸦

## 世界构成

- **角色**：小灰哥（主 IP）、小暖（女友，偶尔配戏）、馒头（柯基，常驻）
- **地点**：两室一厅（客厅/开放厨房/卧室/工作房/阳台）+ 深夜城市（街头、末班地铁）
- **风格**：扁平灰底、黑色粗手绘线、思想泡泡=内心可视化、乱线团=内耗、唯一亮色=洞见
- **叙事**：「慢慢想明白」——每篇一次情绪/认知交手，诚实的小进度条
- **规则**：画幅形式 / 内心可视化必画 / 禁止吉祥物感 / 全灰+唯一亮色
