# 小柴暖夜场景体系

## 统一公式

「一个暖光源 + 一件被认真对待的小事」。场景是老房子的室内夜晚，物件是小柴的配角。

## 场景库

- **烛光桌前**：木桌、两三支高低不一的蜡烛（烛泪痕）、火柴盒与散落火柴梗、待用的物件（手电、电池、书本）。
- **停电的客厅**：家具剪影沉暗部、窗户透进一丝冷夜色（唯一允许的冷色，只做陪衬）、小柴手中的手电或烛台是主光。
- **深夜厨房**：炉火/一盏小灯、壶嘴蒸汽、茶杯与罐子。
- **窗边雨夜**：雨痕玻璃、窗外远处一点模糊暖光、杯中热气。
- **阁楼工作台**：台灯锥形光域、旧收音机、螺丝刀与零件、线轴与工具。

## 光源情绪表

- 烛火 = 停电的镇定、脆弱但稳
- 火柴 = 决定的瞬间（划亮的那一帧常是片子的高潮）
- 台灯/油灯 = 深夜的专注与旧时光
- 炉火 = 等待与暖意

## 构图纪律

9:16 竖屏：小柴中下 1/3 居中或微偏，光源贴近他的手；上部留暗部纵深与氛围；四周 vignette 压暗 ≥25% 画面。
