# 小柴 IP 设定

## 形象拆解

- **头**：一个粗细均匀的黑色圆圈，圈内部留纸面底色（褐白）；眼睛为两个小黑点，眉毛两道短弧——情绪全靠这两组的角度与位置。
- **嘴**：默认无嘴；需要时一条极短弧线，抿嘴或浅笑，从不张嘴大喊。
- **身体**：一条略带弧度的黑线（认真时挺直、疲惫时微驼）。
- **四肢**：黑线，肘膝可弯；手是线端小弯钩（能握、能捏、能扶），脚是两个小黑短横/圆点。
- **比例**：头占身高约 1/4~1/3，瘦长、安静。

## 性格

认真、安静、韧性强。停电不慌、夜深不闹；他是把自己照顾好的那种人——划火柴、换电池、烧水、等天亮。

## 情绪状态（A-G）

| 版 | 状态 | 眉眼 | 肢体 |
|---|---|---|---|
| A | 专注 | 平眉、两点评视手头 | 俯身向前 |
| B | 思考 | 眉微皱、眼看斜上 | 一手托下巴 |
| C | 谨慎 | 眉压低、眯眼 | 身体后倾半步 |
| D | 平静 | 平眉平眼 | 直立垂手 |
| E | 疲惫 | 眼半闭 | 微驼、扶桌 |
| F | 守护 | 眉平、目光柔和向下 | 双手捧/拢住光源 |
| G | 安心 | 闭眼浅弧 | 坐姿放松 |

## 动作库

划火柴、点蜡烛、拢手护火、拧收音机旋钮、装电池、手电照物、捧茶杯、坐窗边看雨、修台灯、给炉子添柴。

## 禁忌

不加衣服、头发、手指分叉、体积阴影；不 3D；不张嘴；不用夸张 Q 版比例。
