# 小柴的暖夜手记

## 核心定位

为中文独处/心理陪伴/生活观察类内容设计和生成风格一致的 9:16 插画短片关键帧。主角是「小柴」：经典黑色火柴人（圆圈头、火柴身躯），置身**暖褐色手绘插画氛围场景**——烛光、台灯、深夜老房间。

## 核心视觉语言

- 深褐近黑的暖夜底色，画面四周 vignette 压暗。
- 每帧唯一暖光源（蜡烛/台灯/油灯），光晕柔和晕染，照亮小柴和他手边的小事。
- 小柴与物件同为黑线手绘；情绪只靠眼睛、眉毛、手的动作。

## 工作流（视频生产）

### 1. 消化选题

提炼一件「暗处的小事」（停电、深夜修物、等水开、给旧收音机换电池），套三拍微结构：暗下来 → 认真做 → 光刚刚好。

### 2. 出 shot list

每镜头写清：场景、光源与色温、小柴的姿态与眼神、手边物件、微动作（火焰摇曳、热气、手部动作）与停留秒数。

### 3. 生成关键帧

- 涉及小柴的每一帧，必须把角色设定九宫格作为参考图传入。
- 关键帧 9:16；设定/表情九宫格 1:1；每张单独生成。

### 4. 检查

唯一光源？黑线一致性？vignette 是否到位？情绪是否克制（不许大哭大笑）？不合格优先重生成。

### 5. 交给视频生成

关键帧 + 微动作提示（烛火摇曳、蒸汽上升、光晕呼吸、眨眼）生成视频片段；音频用安静室内底 + 细小物件音（划火柴、旋钮、水开），BGM 只用极简钢琴或弦乐长音。
