# 提示词模板

> 所有提示词共享风格前缀（STYLE）；参考图始终传 `assets/family.jpg`（媒体库 assetId 见 world.json evidence）。

## STYLE 前缀

```
温暖克制的生活系童话插画，软糯微缩世界感（soft miniature world / diorama）：
极简圆润的几何形体角色，大头小身体，清晰轮廓略带手工感；
低饱和奶油质感色块，哑光柔软如纸张/粘土，轻微颗粒手工痕迹；
柔和的环境光，阴影浅而软，无强明暗对比；
表情克制呆萌微妙，构图稳定留白充足，细节集中在角色与叙事关键区域；
保持「巨大人类世界 × 很小的角色」尺度关系；
不写实、不三维渲染、不厚涂、不夸张卡通、不要霓虹色和复杂光影。
```

## 1. 角色设定集（1:1）

```
角色设定集，1:1 正方形，白色背景，{STYLE}。
主角：{名字}，{物种}，{身份}。严格保持参考图中该角色的形象：{外形锚点}。
内容布局：左侧三视图（正面/侧面/背面全身），
右上四个表情特写（{4 种情绪}），
右下三个常用动作（{3 个动作}）。
```

## 2. 场景全景（16:9）

```
场景全景图，16:9 横版，无文字，{STYLE}。
画面：{场景名}——{3-6 个空间元素}。
色调：{主色调}。
{可选：一个小小身影做某事，强调尺度感}。
构图留出人物活动空间。
```

## 3. 后台解释对比关键帧

```
单幅关键帧，{9:16 或 16:9}，{STYLE}。
画面讲一个「后台解释」：人类世界现象是「{人类看到什么}」，
小小世界的后台真相是「{部门+角色+正在做什么}」。
主角：{角色}，正在 {具体动作与状态}，场景：{地点+2-3 个锚点物}。
情绪基调：{可爱/忙碌/荒诞/温暖}。
```

## 4. 意外/事故关键帧

```
单幅关键帧，{画幅}，{STYLE}。
任务出了意外：{任务本来是什么}，结果 {意外：走错地方/拆坏设备/连锁反应}。
画面：{角色的慌乱反应 + 事故现场的荒诞画面}。
保持可爱温暖，不画灾难恐怖感。
```

## 使用示例

> 后台解释关键帧：「人类看到‘今天突然降温’，后台真相是天气部门临时修改了温度参数。」
> → 阿芽紧张地扳动一个巨大的温度旋钮，小云在旁边瑟瑟发抖变成灰色，背景是云海工作站。

> 意外关键帧：「本该下在城市的雨，被小云送到了沙漠上空。」
> → 小云委屈地悬在沙漠上空下着一小片雨，地面的仙人掌撑着树叶伞，阿芽拿着任务单在远处狂奔。
