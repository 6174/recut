# 核心视角与喜剧机制

## 三条世界规则

### 规则一：人类不知道他们存在

两个世界不是两个宇宙，而是**同一颗地球的不同尺度与不同视角**。人类生活在巨大的现实世界，小小生物生活在现实世界的缝隙里。他们使用人类世界的物体作为设施：

| 人类世界 | 小小世界 |
| --- | --- |
| 废弃纸箱 | 仓库 |
| 一根电线 | 高速公路 |
| 下水道 | 一座城市 |
| 服务器 | 高科技办公楼 |
| 树叶 | 一把伞 |
| 纽扣 | 一张桌子 |

### 规则二：他们不是神

他们无法随意改变世界，只能**维护、协调、修复、传递、观察和处理问题**。很多事情他们也解决不了，甚至会把事情搞得更糟：天气会出错、机器会坏、任务会延误、信息会传错、会议会开过头、方案会失败、同事会犯错。这不是完美运行的幻想世界，而是**像现实世界一样经常出现小问题的社会**。

### 规则三：巨大的地球只是普通工作日

- 一场暴雨 = 天气部门的临时加班
- 一次科技突破 = 实验室员工突然跑通了实验
- 一次互联网热点 = 信息部门彻夜处理消息
- 一次城市故障 = 地下维修工在窄管道里抢修
- 一次全球新闻 = 办公室里突然响起的警报

**宏大的现实，在他们眼里都是具体而琐碎的工作。**

## 后台解释（核心叙事视角）

所有故事遵循：**从小动物社会的角度重新解释人类世界**。不是解释真实科学原理，而是创造有趣的「后台解释」。

| 人类世界 | 小小世界 |
| --- | --- |
| 手机突然没信号 | 通信部门的豆芽发现一个信号节点坏了 |
| 今天突然降温 | 天气部门临时修改了温度参数 |
| 新闻登上热搜 | 信息部门收到一张巨大的热点工单 |
| 城市停电 | 地下工程组正在抢修一条电力线路 |
| AI 出现新功能 | 科技实验室里有人终于把实验跑通了 |
| 地铁晚点 | 地下维修组又在抢修 |

## 世界气质

可爱、温暖、轻松、日常、荒诞、观察性强。不是史诗、不是冒险、不是黑暗世界、不是超级英雄。是**一本正在发生的、关于地球后台工作人员的生活绘本**。

角色会：上班、开会、吃东西、抱怨、摸鱼、加班、犯错、帮助别人、解决问题、偶尔制造新的问题、下班回家。他们面对的事情可能很大，但反应通常很普通。

## 六种喜剧机制

1. **尺度反差**：人类世界的大问题，对他们只是一个小任务。
2. **认知反差**：人类认为事情自然发生，他们知道背后有人在处理。
3. **工作反差**：宏大的世界问题，被当成普通工作处理。
4. **生物反差**：不同生物的身体特征自然成为工作能力。
5. **现实反差**：他们同样会犯错、摸鱼、迟到、抱怨、加班。
6. **意外反差**：一个小问题，可能引发巨大的连锁反应。

## 内容公式

**现实世界事件 × 小小世界的后台视角 × 角色的日常反应 × 意外与反差 = 小小地球事务所故事**
