# 风格 DNA 与 QA 清单

## 整体气质

**温暖、克制、轻松、带一点荒诞感的生活系童话。**
扁平手绘绘本 + Soft Miniature World（微缩世界感）：可爱但不幼稚、简单但不单薄、幽默但不喧闹。

关键词：`Soft Miniature World` · `Warm Whimsical` · `Simple Organic Shapes` · `Low Saturation` · `Matte Texture` · `Diorama` · `Animal Characters` · `Subtle Humor` · `Everyday Fantasy` · `Cozy` · `Handcrafted` · `Minimal Detail` · `Cinematic Composition`

## 造型

- 极简、圆润、软糯的几何形体；以清晰轮廓为核心，避免复杂解剖结构
- 大头、小身体、短肢体的略夸张比例
- 生物特征适度简化、拟人化，但不「人类化」
- 轮廓略带手工感，不追求机械般绝对规整

## 角色视觉

- 以动物 / 小生物 / 非人类生命体为角色基础，必须保持生物可识别性
- 每个角色依靠体型、轮廓、耳朵、尾巴、眼睛、配饰建立辨识度
- 表情简单，主要通过眼睛、嘴巴和身体姿态传递情绪
- 情绪表达偏**克制、呆萌、微妙**，而不是夸张卡通
- 角色之间有明显体型、颜色、性格视觉差异
- 可爱不仅来自外形，更来自动作、表情、习惯和行为

## 色彩

- 低饱和、柔和、偏奶油质感；暖色为主 + 少量清爽冷色
- 避免高纯度、强烈霓虹色
- 单个画面控制在有限主色体系内
- 角色与环境形成柔和但明确的色彩层级
- 角色基色：水豚棕、螳螂绿、章鱼粉、甲虫叶绿、水獭棕、寄居蟹橙、云白；地下用青灰+暖黄；夜景用深夜蓝+屏幕暖光

## 材质与光影

- 哑光、柔软、略带纸张 / 粘土 / 绒面触感；轻微颗粒、纤维或手工制作痕迹
- 避免过度真实的皮肤、毛发、金属和玻璃材质
- 柔和的大面积环境光；轻微暖色阳光、窗光或漫反射；阴影浅而边缘柔软、有重量感
- 不追求电影级强烈明暗对比；整体明亮、舒适、安静

## 空间与环境

- 强调**小尺度世界观**：明显的 miniature / diorama（微缩模型/玩具屋）感
- 日常空间（家、街道、办公室、管道）被重新缩小和童话化；家具道具略夸张、玩具般比例
- 背景不是装饰，而是参与叙事的视觉元素；大量留白，角色是视觉中心
- Zoom-in 能看到材质、表情和小道具；Zoom-out 仍保持统一世界结构
- 永远保持「巨大人类世界 × 很小的角色」的尺度关系：电脑是信息墙、下水道是主干道、服务器是科技城市

## 构图

- 简洁、稳定、偏平衡式构图；角色占据明确视觉中心
- 前景 / 中景 / 背景有层次但不过度复杂
- 大量使用正面、侧面、三分之四视角
- 偶尔使用略微俯视的「玩具屋 / 模型世界」视角

## 线条与细节

- 尽量少线条、少纹理、少复杂细节
- 依靠**轮廓 + 色块 + 明暗 + 小型道具**建立信息
- 细节密度集中在角色和叙事关键区域，非关键区域主动简化

## 叙事气质

- **日常生活被轻微地陌生化**——不追求宏大世界观，让普通事情显得有趣
- 幽默来自角色行为、关系和环境，而不是夸张视觉特效
- 一种「认真生活的小生物们」的感觉

## 场景视觉原则

- 场景必须快速表达「这里是什么地方」：办公室=桌子电脑文件公告板；地下=管道电缆岗亭；实验室=设备屏幕；城市=道路建筑商店
- 场景承担「解释世界」，角色承担「推动故事」

## 产出形式

- 角色设定集：1:1（三视图 + 表情 + 常用动作），每张单独生成，不拼角色
- 场景全景：16:9，空镜无角色或仅点缀小小身影强调尺度
- 关键帧：按目标视频画幅（竖屏 9:16 或横屏 16:9）

## QA 清单（生成后逐项复核）

1. **生物可识别性**：角色一眼能认出是什么生物？没有被画成无差别圆球？
2. **气质准确**：温暖克制、呆萌微妙？没有夸张卡通、厚涂、强对比、霓虹色？
3. **微缩感**：画面有 miniature / diorama 玩具屋质感？材质哑光柔软带手工感？
4. **尺度关系**：能读出「巨大人类世界 × 很小角色」？
5. **构图**：角色在视觉中心、留白充足、层次简洁？
6. **后台视角成立**：画面讲「后台解释」而不是科学原理？
7. **角色一致性**：与 `assets/family.jpg` 的形象锚点比对（配色、配件、体型）。

不合格优先重生成，不要局部修补。
