# 阿蛋 IP

## 角色定义

阿蛋是深夜独处治愈系短片的固定主角。他不是吉祥物，而是观众的分身：一个独居的普通都市年轻人，安静、有点丧、但温柔；他不靠台词讲故事，靠场景、物件和微小的动作。

默认每支短片都有阿蛋。他必须承担画面的情绪与动作主体，不能只是站桩。

## 外形

- 圆白蛋形头，光滑的圆，没有发型，无鼻子无嘴（或极小一笔嘴）。
- 两只小黑点眼，默认平静放空；情绪靠眼睛的微小变化（一点下弯 = 难过，弯成弧 = 微笑）。
- 红色 oversized 连帽卫衣，帽子常塌在背后；红色是全画面唯一的暖色主色。
- 黑色细火柴腿，走路一颠一颠。
- 线条粗、手绘涂鸦感、轻微抖动，扁平色块，无渐变。

## 性格

- 安静、丧而温柔；不卖惨、不鸡汤。
- 自嘲式冷幽默，但更多时候选择沉默。
- 深夜才醒着的人：失眠、加班后、周末独处。
- 会对物品说话（咖啡杯、猫、台灯），把它们当朋友。

## 情绪版（生成视频/关键帧时按此选状态）

- A 放空：瘫坐沙发，头顶一点点星空，咖啡杯冒热气。
- B 微丧：蜷在沙发角落，卫衣帽子戴上，灯只开一盏。
- C 治愈：捧着热杯子哈气，窗边有一盏暖光或一只猫。
- D 期待：盯着手机屏幕亮起，眼睛放大。
- E 失落：屏幕暗下去，头低下去，帽子滑下来盖住半张脸。
- F 微小行动力：给泡面计时三分钟、给绿植浇水、把外卖盒摆整齐。
- G 陪伴：和沙发上的猫背靠背，谁也不说话。

## 常见动作库

抱膝坐沙发、捧杯子哈气、举手机等消息、给泡面等三分钟、趴窗台看楼下、给猫顺毛、裹紧毯子。

## 禁止

- 不要画成可爱吉祥物贴纸、儿童卡通、Q 版大眼萌。
- 不要给他加头发、大嘴、腮红。
- 不要鸡汤大字、励志海报感。
- 不要让画面变成精致动漫画、厚涂、渐变光效。
- 不要让阿蛋只是站桩；必须有情绪动作或物件互动。

## 判断标准

去掉物件互动与留白后，如果画面失去「深夜独处的呼吸感」，说明这张图没有抓住 IP 的核心语言。
