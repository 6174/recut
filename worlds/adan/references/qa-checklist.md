# QA 检查清单

生成后逐项复核，不合格优先重生成，不把问题图直接交付。

## 角色一致性

- [ ] 圆白蛋形头，无发型、无大嘴、无腮红
- [ ] 两点小眼，情绪表达符合所选情绪版状态
- [ ] 红卫衣 oversized、色档统一
- [ ] 黑色细火柴腿

## 风格纪律

- [ ] 黑色/夜色背景，无渐变、无噪点、无厚涂
- [ ] 线条粗、手绘抖动、非矢量
- [ ] 黑色留白 ≥ 50% 画面

## 色彩纪律

- [ ] 红卫衣是唯一主角色且一眼可见
- [ ] 暖黄每帧最多一处（热气/台灯/店灯/手机屏光四选一）
- [ ] 蓝色只给沙发/城市冷光

## 场景锚点

- [ ] 沙发蓝色与脏旧感跨镜一致
- [ ] 黄杯子在左侧扶手、书在右侧扶手
- [ ] 星点 5-8 颗，无银河

## 视频纪律

- [ ] 竖屏下 1/3 主体、上 2/3 夜空
- [ ] 一帧一情绪，微动作明确
- [ ] 无吉祥物感、无鸡汤大字
