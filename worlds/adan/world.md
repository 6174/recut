# 阿蛋的深夜客厅

## 核心定位

为中文深夜独处/情绪治愈类内容设计和生成风格一致的 9:16 短片关键帧与配套设定图。主角是「阿蛋」：圆白蛋形头、两点小眼、红色 oversized 连帽卫衣、黑色细火柴腿。舞台：深夜客厅的蓝色旧沙发（主场）+ 深夜城市场景体系（便利店/末班地铁/雨夜公交站/天台/街头/窗边）。

## 核心视觉语言

- 大面积深夜黑 + 黑色粗手绘线 + 扁平三色（白/蓝/红），红卫衣是唯一主角色。
- 情绪靠微表情（眼睛的小变化）、物件互动（热气、猫、亮窗）和黑色留白表达。
- 每帧最多一处暖黄光源。

## 工作流（视频生产）

### 1. 消化选题

提炼核心情绪命题（等消息、失眠、周日傍晚、便利店…），套三幕微结构：陷入 → 觉察 → 松开一点。

### 2. 出 shot list

每镜头写清：场景与机位（竖屏下 1/3 主体）、阿蛋的情绪版状态（A-G）、物件与光源、是否用暖黄、停留秒数与微动作。

### 3. 生成关键帧

- 涉及阿蛋的每一帧，必须把角色设定集/情绪版作为参考图传入。
- 关键帧 9:16；设定/情绪/表情九宫格 1:1；场景全景 16:9。
- 不复刻已有范例构图，每次从当前命题重新发明画面。

### 4. 检查

按 `references/qa-checklist.md` 逐项复核：角色一致性、留白纪律、暖黄唯一性、场景锚点（沙发/杯子/书）。不合格优先重生成。

### 5. 交给视频生成

关键帧 + 微动作提示（热气飘动、眨眼、慢推）生成视频片段；音频用安静环境底 + 单一氛围音，BGM 只用极简钢琴/lofi。

## 资源口径

- `assets/` 的角色设定集/情绪版/表情集（primary）：生成时的**一致性锚点**，必须随参考图传入；同时是低频校准基准。
- `assets/living-room-panorama.png`：客厅场景锚点。
- `examples/` 的 9:16 成品范例：定义情绪密度与画面节奏，**不复刻构图与命题**。
- 角色外形以「阿蛋」实体（含 body 全文）为准；风格以「风格 DNA」与规则实体为准。
