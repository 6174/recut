# Features
- 主色克制：主色只给功能性元素（每屏唯一主 CTA、focus ring、进度/开关），装饰性用途（眉标、徽章、图标、标签、横幅、hover 边框、面包屑、激活 tab）一律用中性 muted/secondary/foreground；重主色 = "AI 味儿太重"。基础表面中性、无色偏（去绿），饱和度只留给语义强调色；装饰性发光/光晕会被当成 bug 删掉。Confidence: 0.85
- 颜色用设计系统 token（`--background`/`bg-background`），不要 ad-hoc 透明度值；配色目标常指向某个既有界面来对齐；关联设计值集中到一个统一的 ts theme 文件作唯一真源；一组相关界面作为同一套调色板协调，不各自调。Confidence: 0.7
- 表面融入父级背景：panel header 与内容同底色，输入条无外层背景（只留内部圆角输入卡）；少用容器框，内容扁平直出。Confidence: 0.7
- 默认字号够大易读；状态色统一（未生成/计划中/待确认用弱灰，饱和色只给真正进行中与失败）；失败/警告状态低调"降低存在感"。Confidence: 0.7
- 网格卡片用正方形（`aspect-square`），视频/影片缩略图用 16:9。Confidence: 0.6
- 内容卡片：圆角外框 + 内 padding + 结构化内容 + 少色彩，与背景和谐；封面内缩留 padding + 内圆角露出背景形成卡片感，同一套卡片语法复用到所有图片/媒体块。Confidence: 0.6
- 空态用居中、浅色、示意性的矢量图标（如"图片"山形）；占位图标画成纯裸形状（不加外框）、bezier 曲线而非硬几何、低对比、描边细轻。Confidence: 0.55
- 页面砍装饰/身份图标，布局保一行，只留必要功能字形（如单个返回箭头）。Confidence: 0.6
- 顶栏动作分主次：主操作（新建/历史）独立图标按钮，次/诊断操作收进一个尾部「更多」溢出菜单；一族相关动作收进单个下拉菜单，不要一排图标。Confidence: 0.7
- 顶部导航靠右不居中；营销 header 只留最少导航项；全局 header 少图标，把状态/工具折进 settings 入口。Confidence: 0.55
- 全局一个快捷 launcher 收拢已装应用/素材库/新增应用（新入口加进同一 popover，新标签页打开）；顶层导航入口 hover 出 popover menu 并统一如此；popover 分区（核心目的地在前 + 最近项约 10 条 +「更多」）。Confidence: 0.55
- app chrome 只留一个返回入口，不显示 logo/wordmark（logo 和 "recut" 都不用显示）。Confidence: 0.6
- 同工作区兄弟页共用一套骨架（同 header 结构、同宽度/对齐、同滚动行为）；滚动放单一外层容器不嵌套；相邻面板 header 高度对齐；各段容器对齐边一致。Confidence: 0.65
- 侧栏面板合并成一列 docked 多面板（Photoshop 式：上属性 + 下 outline），分隔条可拖动调高、常驻不折叠；次级/预览面板镜像主工作台的布局与交互。Confidence: 0.75
- 不要固定在容器边缘的 sticky 操作条（动作放正常内容流，冗余就直接删）；header/chrome 控件用朴素 icon-only 按钮、与相邻 header 图标一致，不用带文字的 Button。Confidence: 0.55
- 菜单/列表项用「左图标右文案」横向行（不用图标在上下的竖排 tile），并按使用频率排序（最常用的在最上面）。Confidence: 0.6
- 选项/类型选择面板：分类分组内的密集卡片网格（3 列，icon 上 label 下）+ 详情预览；分组保留但组数要少，子类用角标区分。Confidence: 0.65
- 新建入口要暴露所有创建渠道（如 world 也要能"导入 zip"）；系统内置类型（场次/镜头）作为独立「生产结构」分组的头等入口出现在新建菜单。Confidence: 0.55
- 只读态要给可操作的出口（clone 到自己可编辑的副本），并用 primary 权重。Confidence: 0.6
- 交互要即时可见反馈（没有 pending/成功/错误反馈的动作算 bug）；长任务要有界（卡过上限自动转 failed/可重试，规则在各状态面统一）。Confidence: 0.65
- loading 要有信息量（说明在加载什么、进度/字节）；无日志/无进度/无超时/无错误的无限 loading 是 bug；要"先进去再分区局部 loading"，不要全屏 spinner 卡住入口（onboarding 闸门只在探测确认需要时才渲染）。Confidence: 0.7
- 渐进渲染 paint-first：先渲染可用部分、慢资源（字体）后补，实现成本高可暂缓；重静态资源（多 MB 字体）要客户端缓存（Cache Storage），首次慢可接受、不能每次重下。Confidence: 0.65
- 视图间导航要客户端无缝（不要整页刷新）、应用内状态变更要即时响应（不要"刷新才更新"）；本地数据要快速渲染，不要长空白 loading。Confidence: 0.55
- 子操作彼此独立（增删一个 chip 不级联影响其他）；选择/附件要显式 opt-in（默认全不选、用「+」逐个加，当前上下文作为可直接 + 的候选内联出现）；chip 限宽并 flex-wrap 多行，截断项 hover 可看全文。Confidence: 0.65
- 表单字段默认可选（只有确有必要才标 required，其余不填也能提交；可选的关联引用如 World 呈现为可清除的 chip，不强制选择）。Confidence: 0.55
- hover 预览/popover 不能遮挡其锚点元素（锚点控件保持可点）；hover 态不能改变元素几何（不要因 hover 出现 × 而抖动/reflow，宁可去掉控件）；元素 hover 与非 hover 外观要一致。Confidence: 0.6
- 输入框要给 placeholder 提示；密钥/凭据字段已保存后默认显示态（打马 + 明确 set/unset），编辑态需显式进入；管理/设置对话以展示为先（默认显示状态 + 「+」/切换，添加/编辑放二级页/对话）。Confidence: 0.7
- 领域对象的管理动作（重命名/删除/重置）就放在该对象那一行（标题旁 manage 图标 → popover）；搜索/筛选框支持直接用已输入文本创建（Enter 或行内「建立「xxx」」项），不要再点 + 重输。超宽要自动 ellipsis，不溢出。Confidence: 0.65
- 批量操作作为单个分组步骤 undo/redo（多选删除一次 ⌘Z 撤销）。Confidence: 0.75
- 状态指示器可点击打开专用管理面板（状态 + 启停 + 实时日志，参照 modal_studio 右上角设置）；托管服务日志在启动/运行/停止每个状态都可查；日志自动滚到最新、完整不静默截断、成功也保留；run 详情完整展示全部输入参数；参考媒体按真实类型渲染与标注。Confidence: 0.65
- 媒体/参考缩略图处处可点开全屏预览（预览里的参考也能点开，处理循环：就地替换 + 返回栈）；内部标记（如 `<reference ... />`）要渲染成富文本/chip 不显示源码；发给模型的 payload 用人类可读标签（编号别名/名字），不用不透明 id。Confidence: 0.65
- 表单/输入状态按单元 persist（细到每个 function/mode 各自一份，重开恢复）；视图状态（右侧预览 focus）与配置值也要跨重启保留；切换/新建会话要真正重置瞬态状态；用户编辑要落库能扛刷新（子上下文里的首次编辑也要持久化到该上下文）。Confidence: 0.65
- 画布是自由画布：任何 entity 可放/建在任何地方，位置不受类型/schema/容器约束；schema/childTypes 只是树的派生视图，不用于校验归属或创建位置；自由 move/copy/paste 是数据模型不能违反的要求。Confidence: 0.65
- 两个正交轴分开：通用归属层级（parentId，类通用文件夹/Notion 文档树，无类型约束，只记"住在哪"，保留现状）vs 语义关系 link（作品→script→scene→shot）；link 是实体→实体的轻量记录、允许环（由解析方处理），只有 parent/tree 保证无环。Confidence: 0.6
- link 是画布上的物理连接：实体要真连在一起，挪到别的容器就自然失去 link（当作特性：让关联的东西就近）；跨父关联留给未来 `reference_node`。Confidence: 0.6
- 类型命名要宽泛（character 显示为「角色」以覆盖动物，改标签不改 id、不需迁移）；更容易被当属性的概念就作既有实体的属性（rule/style 归到 world）；类型不写死某模式的必填槽位，产物/字段按 role/label 按需挂、具体模式记在实例自身 metadata。Confidence: 0.7
- 默认实体集要精简/准确/可运行（只留跑通核心环的最小集合），但现实创作者必不可少的类型（如道具/prop）要进默认；不为覆盖而扩。Confidence: 0.7
- 拒绝冗余派生字段（`editCapable`），消费方直接读模型已声明的能力（`inputModes.includes("image")`）；数据模型改动要追踪所有下游消费方（渲染/节点契约、值比较/相等、派生状态）。Confidence: 0.6
- 读投影只给 meta（id/type/name/parent/cover/时间），内容体/属性藏在按需 get 后；用单一统一集合（每个 item 自带区分属性，如带 role 的 relations 数组），不按命名启发式分出特例字段；一个概念只在一处表达（不重复渲染）。Confidence: 0.65
- 层级模型的能力在每一层都可用（scene 的产出 video 也作属性挂上）；父子包含关系（script→scene→shot）作为显式结构化数据（父 schema 声明可持有的子类型）+ 拖拽直建子实体；对象 vs 属性用统一判据（是否需要独立身份：id/关系/容器角色/自有属性）并写进文档。Confidence: 0.55
- 画布层级要浅（"无限画布 ≠ 文件夹树"）：锚点实体（角色/地点/道具/作品）直接放 world 根，生产实体（脚本/场景/镜头）在 work 子世界里全部铺平、不层层嵌套；写进 skill 作为显式约束。Confidence: 0.7
