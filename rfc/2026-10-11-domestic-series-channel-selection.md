# RFC: 国内系列栏目选题 —— 复用机制、另占格子的 5 个原创方向

- 状态：提议（待拍板）
- 作者：Recut
- 日期：2026-10-11
- 决策范围：国内（抖音 / 小红书 / 视频号）首批 5 个「固定角色 / 世界观 + 固定选题域 + 可持续更新」的**原创**栏目方向、机制公式、候选矩阵、组合与上线顺序、平台与合规、由栏目倒推的产品/运营动作；不含脚本与分镜、不含海外栏目
- 关联：`rfc/2026-10-10-video-gtm-series-creators.md`（人群与三类账号）、`rfc/2026-10-10-video-gtm-user-focus.md`（复刻楔子 / 生成之后 / 一个世界观无限条）、`rfc/2026-08-16-marketing-content-plan.md`、`rfc/2026-10-03-world-case-genre-selection.md`

## 摘要

用户给的四个已有爆款（**女生讲人生 / 外星人讲科普 / 猫讲旅游 / 狗讲房产**）是**机制样本，不是选题清单**——它们已经跑通，说明对应的格子**已被占**；新人再进去，只能拼执行与成本，没有结构优势。

它们能成，是因为共享同一个机制：

> **一个非常规的讲述者（角色 / 世界观）× 一个高价值垂直领域 × 一条能无限生成选题的「世界规则」× 一条清晰的变现。**

本 RFC **只抄机制，去占别人还没做的格子**，给出 5 个原创方向：

| # | 栏目（暂名） | 讲述者 / 世界观 | 领域 | 组合角色 | 平台 |
|---|---|---|---|---|---|
| 1 | **《身体公寓》** | 把人体当一栋公寓，器官是住户（群像卡司） | 健康 / 作息 / 饮食 | **强世界观**（卡司群） | 抖音 + 小红书 |
| 2 | **《2050 观测站》** | 一个来自 2050 的观测员，回看今天 | 科技 / AI / 消费趋势 | **轻量品牌**（单角色） | 抖音 |
| 3 | **《城市如是说》** | 「中国城市宇宙」，每个城市是一个人 | 文旅 / 本地生活 | **无限世界**（可扩展群像） | 抖音 + 小红书 |
| 4 | **《家电求生指南》** | 家里的电器家具是人（群像卡司） | 家电 / 3C / 家居消费 | **强变现**（带货） | 抖音 |
| 5 | **《毛孩子急诊室》** | 一家宠物医院，拟人化的毛孩子问诊 | 养宠 / 宠物健康 | **纵深变现**（垂类） | 抖音 + 小红书 |

一个共同点：**都是「一个固定世界观 + 一群固定角色 + 一条能长选题的规则」**——这正是 Recut 的 World / 跨集一致性 / 「一个世界观无限条」最能兑现价值的地方，也是竞品最难抄的地方（**抄得了题材，抄不了你的世界**）。

## 0. 研究说明（诚实标注）

- **浏览器直采受阻**：抖音对无头浏览器返回滑块验证码（`rmc.bytedance.com/verifycenter/captcha`），小红书返回「IP 存在风险（error 300012）」登录页。agent-browser 用的是自带 Chromium、挂不上你本机已登录的 Chrome profile；仓库里现存的抖音 cookie（`~/ws/2025/douyin-视频`）是 2025-05 的、已过期。**因此本文数据来自公开检索与行业媒体二次核实，不是平台一手抓取。**
- **未做**：未登录平台、未拉实时榜单、未逐条核对播放/粉丝数（均为多方报道口径，可能有时点差异）。
- **可补做**：若你提供新鲜 cookie，或允许我打开有头浏览器扫码登录，我补一份「每个格子里已有哪些真实账号 + 实时数据」的占位排查附录（见 §9 未决 A）——**这一步很重要：发明之前要先确认格子真的空着。**

## 1. 判断（TL;DR）

1. **抄机制，不抄题材**（也是 series-creators RFC 的原话：分段的轴是生产重复度，不是题材）。你给的四类之所以「现在已有」，正说明**格子已被占**；我们的机会在「同一个机制 × 没被占的组合」。
2. **好栏目 = 四要素齐备**：① 非常规讲述者（是「角色 / 世界观」，不是「人设标签」）；② 高价值领域（能无限出选题 + 有钱可挣）；③ 一条**世界规则**（保证选题可无限长、跨集不散）；④ 一条清晰变现。
3. **优先选「天生是一个 World」的**（有卡司 / 有世界规则）——单角色号谁都能做，**群像世界才是护城河**（跨集一致、角色复用、规则即模板）。
4. **四个避坑**：不做**公共版权形象**（字跳已在为热门形象申请著作权，蹭梗 = 给平台打工）；不做纯转场特效（红海）；不做重资产纯 AI 短剧（要规模）；不做纯蹭热点的「无世界规则」号（三五条就枯竭）。

## 2. 机制拆解：能抄什么、不能抄什么

### 2.1 四个已有爆款「为什么成」

| 已有方向 | 讲述者 | 领域 | 世界规则（能长选题的原因） | 变现 |
|---|---|---|---|---|
| 女生讲人生 | 固定女性人格 | 成长 / 情绪 | 「一个命题 → 一套建议」可无限 | 知识付费 / 好物 |
| 外星人科普 | 外星人 + 人类 | 科学 / 规律 | 「一条科学原理 → 一集」无限 | 科普品牌 / 教育 |
| 猫讲旅游 | 拟人猫 | 文旅 / 地域 | 「一个地方 → 一集」无限 | 文旅 / 本地生活 |
| 狗讲房产 | 拟人动物 | 房产 | 「一个买房话题 → 一集」无限 | 房产平台 / 线索 |

### 2.2 三个可迁移机制 + 两个不可迁移

**可迁移（机制）**：

- **讲述者要是「角色」**：有稳定形象、性格、说话方式，能跨集一致、能积累——不是「一个人设标签」。
- **领域要能长选题**：垂直、高价值、天然可拆成无限子题（一个地方 / 一个原理 / 一个话题 = 一集）。
- **每集有固定模板**：结构越规整，第 N 条越快，复利越强。

**不可迁移（别抄）**：

- **具体题材**（萌宠×文旅、动物×房产、外星人×科普、数字人×成长都已拥挤）。
- **具体形象**（版权风险）。

### 2.3 变现规律（决定了怎么选格子）

- **流量靠形象与情绪，变现靠垂直与系列，长期靠自有角色版权。**
- 成熟号的星图报价才高（一条 25–60 万），纯 AI 萌新即使有爆款也常**变现困难**——所以栏目从一开始就要绑定一条「垂直变现」。
- 宠物 / 家电 / 母婴 / 本地生活这类**带货与线索属性强**的品类，变现比纯知识更实在。

## 3. 五个原创方向（具体形状）

> 每个方向标注：讲述者 / 世界观（= World 资产）、内容域、每集结构（= 可复用模板）、为什么新、为什么能火、变现、Recut 映射、风险、示例选题。名字为暂名。

### 方向 1 ·《身体公寓》（候选：《身体公寓》《器官议事厅》）

- **世界观 / 卡司**：把人体当成一栋公寓，器官是住户——胃（嘴馋劳模）、肝（夜班解毒工）、胰岛素（送快递的）、免疫警长、大脑（房东 / CEO）、脂肪（囤货储户）。固定形象与性格，可长期出场。
- **内容域**：作息、饮食、久坐、减脂、体检指标、情绪与身体的关系。
- **每集结构**（≈45–75 秒）：`一个生活场景（熬夜 / 奶茶 / 一张体检单）→ 器官住户吵起来 → 讲清机制 → 一条可执行建议`。
- **为什么新**：中文短视频里把**器官做成「公寓群像系列」**基本空白（《工作细胞》是灵感，但形态、语言、驱动完全不同——我们不做拟人动画剧，做短视频科普群像）。
- **为什么能火**：健康是全民刚需；拟人 + 群像 = 戏剧性 + 萌；知识密度可高可低，易传播。
- **变现**：健康食品 / 运动 / 家居健康（合规口径）、体检与保险的科普合作、出版。
- **Recut 映射**：卡司群 = World `character`；「公寓规则」= `identity.constraints`；每集模板 = 可复用 `script`。
- **风险**：医疗合规——只做科普、不做诊断、不承诺疗效；不能伪科学。
- **示例选题**：① 熬夜那晚，肝在干嘛 ② 奶茶进城后，胰岛素的一天 ③ 为什么你一紧张就胃疼

### 方向 2 ·《2050 观测站》（候选：《2050 观测站》《未来回信》）

- **讲述者 / 世界观**：一个来自 2050 的观测员（固定形象 / 声音），守着一台「历史数据库」，回看 2020 年代。
- **内容域**：科技 / AI / 互联网 / 消费 / 社会现象的趋势解读。
- **每集结构**（≈40–70 秒）：`捡起今天的一件东西（一个 App / 一个热词 / 一个产品）→「在我来的那条时间线上，它后来……」→ 讲趋势 / 原理 → 一句未来式忠告`。
- **为什么新**：「未来回看」是经典叙事手法，但在国内 AI 系列号里**没人占位**；而且它天然能接**每日热点**（时效性就是独立站式优势）。
- **为什么能火**：反身性（AI 讲 AI、未来讲今天）自带话题；可蹭热点、可量产、成本低。
- **变现**：3C / AI 工具 / 科技品牌商单、课程、科技媒体合作。
- **Recut 映射**：**最轻的 B 类验证**——单固定角色 + 固定「观测站」视觉，验证「跨集一致 + 蹭热点」的产线。
- **风险**：选题要持续供给；别飘成纯科幻，要落回真实趋势，避免误导。
- **示例选题**：① 2050 年回看「短视频」 ② 你们 2026 年还在手动做 PPT？ ③ 这条时间线上，外卖骑手后来怎样了

### 方向 3 ·《城市如是说》（候选：《城市如是说》《中国城市图鉴》）

- **世界观 / 卡司**：「中国城市宇宙」——每个城市是一个有性格、有口音、有职业的人；可无限扩展（几百个城市 = 几百集）。
- **内容域**：城市性格、美食、历史、机会、房价、避坑。
- **每集结构**（≈45–80 秒）：`城市自报家门 → 讲一个性格 / 一个冷知识 / 一个机会 → 一句本地化金句`。
- **为什么新**：城市宣传片多，但**把城市拟人成固定角色群的系列号几乎没有**。
- **为什么能火**：地域认同是最强的情绪之一（「我们市」）；观众可点单（「求讲我的城市」），互动性极强。
- **变现**：文旅 / 本地生活 / 城市品牌 / 招商、地方特产带货（契合「跟着微短剧去旅行」等政策）。
- **Recut 映射**：**一个大世界观 + 上百个角色**，是「一个世界观无限条」最字面的载体。
- **风险**：**避免地域黑**；要与官方宣传差异化（有性格、敢说真话、有梗）。
- **示例选题**：① 如果成都（长沙 / 西安）是个人 ② 深圳的自述 ③ 一个东北城市的江湖气

### 方向 4 ·《家电求生指南》（候选：《家电求生指南》《我家电器有话说》）

- **世界观 / 卡司**：家里的电器家具是人——冰箱（囤货王）、洗衣机（洁癖）、扫地机（社畜）、路由器（全家命脉）、空调（怕热）。群像可扩展（新家电 = 新角色 = 新集）。
- **内容域**：家电 / 3C 选购、使用技巧、智商税避坑、家居好物。
- **每集结构**（≈45–75 秒）：`一个纠结 / 踩坑场景 → 该家电自述「我到底该怎么选、怎么用」→ 3 条要点 → 一句忠告`。
- **为什么新**：家电测评号很多，但**「拟人化家电群像 + 科普」没有**——把冷冰冰的参数变成有性格的吐槽。
- **为什么能火**：家电 / 3C 是**高客单、高佣金**品类 +「避坑」是强需求 + 拟人化降低理解成本。
- **变现**：**家电 / 3C 带货（佣金高）+ 品牌商单**（本方向变现最直接）。
- **Recut 映射**：固定卡司 + 结构化脚本（参数 / 要点模板），复用度极高。
- **风险**：信息不能瞎编、要真实可核；保持相对客观，别变成纯广告。
- **示例选题**：① 空调到底买几匹 ② 洗衣机「自清洁」是智商税吗 ③ 路由器放哪信号最好

### 方向 5 ·《毛孩子急诊室》（候选：《毛孩子急诊室》《宠物医院的一天》）

- **世界观 / 卡司**：一家宠物医院里，**拟人化的毛孩子既是「病人」也是「医生」**（猫医生 / 狗护士 / 说人话的患者）；固定场景池（诊室 / 候诊区 / 药房）。
- **内容域**：养宠健康、喂养、行为、就医避坑。
- **每集结构**（≈40–70 秒）：`一个养宠常见状况 → 拟人宠物问诊 / 吐槽 → 讲清原因 → 一条照护建议`（规则：一集一病例）。
- **为什么新**：宠物剧情号很多，但**「宠物医疗 / 健康」这个子格基本空着**——挑宠物热潮里最垂、最刚需的一块。
- **为什么能火**：养宠人群爆发 + 宠物健康是刚需 + 萌。
- **变现**：宠物食品 / 用品 / 医疗带货、宠物保险、宠物医院合作。
- **Recut 映射**：固定卡司 + 固定场景池 +「一集一病例」规则（规则即模板），是标准 World。
- **风险**：医疗建议别越界（不替代兽医诊断）、标注科普口径。
- **示例选题**：① 猫为啥总吐毛球 ② 狗子夏天能不能剃毛 ③ 换粮期拉肚子怎么办

## 4. 候选矩阵与取舍（把创意过程摊开）

> 规则：先穷举「讲述者 × 领域」的格子，再按四要素（角色 / 可长选题 / 高价值 / 变现）筛选。✅ = 入选；○ = 备选；✗ = 淘汰。

| 讲述者 / 世界观 | 领域 | 新颖度 | 变现力 | Recut 契合 | 结论 |
|---|---|---|---|---|---|
| 器官群像（身体公寓） | 健康 | 高 | 大 | 极高（群像世界） | ✅ 1 |
| 来自 2050 的观测员 | 科技 / 未来 | 高 | 中大 | 高（单角色，轻） | ✅ 2 |
| 城市宇宙（城市拟人） | 文旅 / 本地 | 中高 | 中 | 极高（无限世界） | ✅ 3 |
| 家电家居群像 | 家电 / 3C | 高 | 极大（带货） | 高 | ✅ 4 |
| 宠物医院群像 | 养宠健康 | 中高 | 大 | 高 | ✅ 5 |
| 婴儿第一人称 | 育儿 / 母婴 | 中 | 极大 | 中（权威性要求高） | ○ 备选 |
| 退休大爷 IP | 养老 / 防诈 | 中 | 大 | 中（偏口播、视频号） | ○ 备选 |
| 拟人律师（法猫） | 法律维权 | 中高 | 中（资质受限） | 中 | ○ 备选 |
| 微生物小队 | 卫生 / 肠道 | 高 | 中 | 中 | ○ 备选 |
| 牙齿精灵 | 口腔健康 | 中高 | 大 | 中 | ○ 备选 |
| 古生物活在今天 | 自然 / 环保 | 中高 | 中 | 中 | ○ 备选 |
| 一枚硬币 / 貔貅 | 理财 | 中 | 大 | 中 | ✗ 暂缓（金融合规敏感） |

**为什么是这 5 个**：

- **凑齐三种「世界形态」**：群像世界（1、4、5）、无限扩展世界（3）、单角色世界（2）——覆盖 Recut 从轻到重的全部能力面。
- **凑齐五种「组合角色」**：1 强世界观、2 轻量品牌、3 无限世界、4 强变现、5 纵深变现。
- **变现都落在真实品类**（健康 / 3C 家电 / 文旅 / 宠物），不是「先涨粉再说」。
- **都不与已有爆款撞题材**，但都复用同一机制——所以我们能做得和他们一样快，却不用挤同一个格子。

## 5. 组合与上线顺序

- **第 1 个月**：先起 **2（《2050 观测站》）与 4（《家电求生指南》）**——2 最轻（单角色，验证「跨集一致 + 蹭热点」），4 变现最直接（验证「角色复用 + 带货」）；两者一起跑出**第 1 条 vs 第 N 条的对比数据**（对外最重要的证据，见 series-creators RFC §3）。
- **第 2–3 个月**：上 **1（《身体公寓》）**做群像世界旗舰（世界观最能打、也最能演示 World）；上 **3（《城市如是说》）**用「观众点单城市」跑互动增长。
- **第 3 个月起**：**5（《毛孩子急诊室》）**做纵深变现（垂类 + 带货），可与宠物品牌合作。
- **与 series-creators 三类账号对应**：2 ≈ A（资讯 / 趋势，先验证）；1/3/5 ≈ B（原创 IP / 固定角色世界，品牌）；4/5 ≈ C（知识 / 垂类，商业化纵深）。

## 6. 平台与合规（硬约束）

- **抖音**：AI 生成内容如实标注；用平台 AI 创作扶持（即梦等）但不做同质化搬运（已有大量下架案例）。
- **小红书**：**AI 辅助内容必须标注**；**AI 虚拟人账号必须在资料页说明并开启「AI 虚拟人」标签**（方向 1、2 尤其注意）；不做批量托管（平台已处置 42 万个）。
- **视频号**：适合 3、5 的二次分发。
- **通用红线**：**健康类（1、5）只做科普、不做诊断与疗效宣称**；地产 / 金融 / 医疗类不误导；所有方向**用自有角色**规避版权（参照字跳为热门形象申请著作权的信号）。

## 7. 由栏目倒推（产品 / 官网 / 运营）

- **产品**（承接 series-creators §4）：让「栏目」成为一等入口；「从已有栏目开新一集」是默认路径（继承角色 / 视觉 / 模板）；一致性要可见可检查。**这 5 个方向是 5 套「生产规范」的实证样本，其中 1/3/4/5 直接压测「群像 + 世界规则」的一致性能力。**
- **官网**：每个方向产出一套证据四件套——成片 + 制作过程 + **可复用的栏目资产（World / 模板）** + 用户下一步；让「看完」能直接变成「用这个栏目起我的号」。
- **运营**：**至少 1 个方向（建议《2050 观测站》或《身体公寓》）作为自有样片账号日更**——「第 10 条那条视频本身就是最重要的营销」。

## 8. 度量（沿用 series-creators 口径）

北极星仍是「用户把一个持续更新的账号建立在 Recut 上」。栏目层面看：**第二次 / 第三次产出率、第 N 条 vs 第 1 条的耗时与人工、跨集一致性达成度、从主题到成片的时间、栏目资产复用次数**。**不用播放量 / 点赞定方向**。

## 9. 未决项（需你拍板）

- **A（先排查占位）**：**发明之前，先确认格子真的空着**。是否提供新鲜 cookie / 允许有头扫码，让我把上表每个方向的「已有账号 + 实时数据」查一遍？强烈建议先做这步，再定稿。
- **B（方向取舍）**：5 个里保留哪几个、用哪些备选替换（如《毛孩子急诊室》→《宝宝视界》/《退休老张》/《牙齿精灵》）？
- **C（先起谁）**：先起《2050 观测站》（最轻）还是《家电求生指南》（变现最快）？建议先观测站。
- **D（真人 vs 纯生成）**：是否引入真人 / 半真人（真人 + AI 目前爆款率更高）？
- **E（平台重心）**：抖音为主 + 小红书图文，还是双平台同步？
- **F（世界形态）**：先做「单角色」（2）还是直接上「群像世界」（1/3/4/5）？群像是护城河，但一致性门槛更高。
- **G（是否海外并行）**：本 RFC 只覆盖国内；海外栏目（YouTube/TikTok）是否另起一篇。

## 10. 边界

- 不做：公共版权形象（版权风险）、转场变装 / 特效炫技（红海）、重资产纯 AI 短剧（需规模）、无世界规则的纯蹭热点号（会枯竭）。
- 不承诺：在跨集一致性达标前，群像类方向（1/3/4/5）不对外承诺全自动。
- 本 RFC 不含具体脚本、分镜与预算；不以播放量作为路线依据。
