# components/

> L2 | 父级: properties 面板

成员清单
component-params-tab.tsx: 组件参数容器，按标题和分组承载可关键帧字段。
element-params-tab.tsx: 元素内建属性容器，过滤可见参数并交给分组编排器。
keyframe-toggle.tsx: 字段右侧的关键帧开关。
param-groups.tsx: 参数的语义分组与可折叠区块渲染器，Background 默认折叠。
property-param-field.tsx: 单个参数的统一 Number、Range、Color、Select 与文本输入。
motion-presets-tab.tsx: 元素/文本 Enter、Exit、Loop 统一折叠分组；组内用紧凑双列缩略卡片高密度浏览，单击即 active 并通过瞬时预览层播放真实动效。
