工作台是 Recut 的主要界面，由五个顶级 Tab 与一个全局 Agent 面板组成。

## 创作台（Studio）

默认入口。展示最近的创作应用、项目列表与最近使用的素材；顶部是 WebGL 动态背景与两条当日的创作引导。在创作框输入想法，可以让 AI 从文字、脚本或素材出发规划一支视频。

## Worlds（世界观）

系统级世界观管理。为角色、场景和叙事规则建立持续上下文，让每一次创作都从同一个世界出发。World 是平台原生能力，不进入应用市场或 iframe。

## 项目

项目的桌面。这里列出你创建的全部项目（每个项目绑定一个项目型 App），可以新建、重命名、删除，或点开进入项目工作台继续创作。

## 素材库（Assets）

平台的媒体库。上传图片、视频、音频，或让 AI 生成并沉淀素材；素材按类型管理、跨项目复用，与 Agent 会话绑定归属。

## 应用（Apps）

已安装的应用与可添加的应用市场。应用是 Recut 能力的载体：安装或自己编写 App，接入新的模型、工具与工作流。项目型 App 用来新建项目，工作区型 App（standalone）直接打开独立工作区。

## 全局 Agent 面板

左侧常驻的 AI 对话面板，可以跨路由保持单一会话。它帮你规划创作、读取素材上下文、执行生成与剪辑任务，是「AI 协同创作」的主要入口。

五个 Tab 共享同一份项目、素材与 Agent 会话——这正是「一个工作台」的意义。
