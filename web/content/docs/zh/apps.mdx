Recut 把创作能力封装成 App：App 用 JavaScript 定义界面、业务与工作流，并接入平台的存储、文件、任务、素材与模型能力。一个 App 就是一类创作能力。

## 什么是 Recut App

- **项目型 App**：绑定用户项目，用来「新建项目」，在项目工作台中使用。
- **工作区型 App（standalone）**：绑定稳定的 App 专属工作区，直接打开，不要求项目命名。

每个 App 由 `manifest.json` 声明身份与权限，`background.js` 承载业务，`ui/` 提供界面。App 之间不互相读取私有数据。

## 应用市场

工作台「应用」Tab 分两栏：

- **已安装**：本机已装好的能力，可新建项目或直接打开。
- **可添加**：应用市场目录，浏览详情后可安装或开始项目。

### 安装应用

- 从市场选择 App 安装：service 会校验 `manifest.json` 后克隆并激活。
- 从 Git 安装：在「应用」顶部把 GitHub 仓库交给 service，校验成功后即安装。
- 内置 App（如 Remotion Studio）随 binary 同步，首次打开即可用。

### 更新与卸载

已安装的 Git App 会定期检查远端更新，出现可安全升级项时工作台提示一键更新；升级保护本地修改。卸载即从应用列表移除，不影响项目文件。

## 官方应用一览

- **AI 短片**：给一个选题，自动梳理叙事结构与分镜，生成可审阅的解说文案与配套 B-roll。
- **Remotion 视频**：把选题、文案与素材编排成可实时预览、可导出的程序化视频，项目是真实 Remotion 工程。
- **声音工坊**：本地语音转写、字幕与 AI 配音；为已授权声音建立可复用角色。
- **封面生成**：按渠道尺寸批量生成并沉淀封面素材。
- **深度图**：在本机把图片或视频转换为可预览的深度图。

## 自己编写 App

开发者可以用 JavaScript 编写自己的 App，接入平台能力。参考「开发 App」文档与公开的 App 创建契约（`/app-standard.md`）。
