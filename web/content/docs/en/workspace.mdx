The workspace is Recut's main interface: five top-level tabs plus a global Agent panel.

## Studio

The default entry. It shows recent creation apps, projects and recently used media, with a WebGL animated header and two daily prompts. Type an idea into the composer to have AI plan a video from text, scripts or media.

## Worlds

System-level worldbuilding. Characters, scenes and narrative rules keep a persistent context so every creation starts from the same world. Worlds are a native platform capability — they don't enter the app marketplace or iframes.

## Projects

Your project desktop. Every project you create (each bound to a project-type App) is listed here — create, rename, delete, or open one to keep creating.

## Assets

The platform media library. Upload images, video or audio, or generate and archive media with AI; assets are organized by type and reused across projects, with ownership tied to Agent sessions.

## Apps

Installed apps and the addable app marketplace. Apps are how Recut carries capabilities: install or write an App to connect new models, tools and workflows. Project-type Apps create projects; standalone Apps open their own stable workspace.

## The global Agent panel

A persistent AI chat panel on the left that keeps a single session across routes. It plans creation, reads media context and runs generation and editing tasks — the main door to AI-assisted creation.

All five tabs share the same projects, media and Agent session — that's what "one workspace" means.
