用你的 Codex 或 Claude Code 驱动视频创作，剪辑不再只是专业人士的事情。你用自然语言说清楚目标，Agent 帮你整理素材、规划镜头、搭建节奏，再把每一步落到可编辑、可撤销的时间线上。你不必先学会复杂的剪辑软件，仍然可以看见、修改并决定最终作品。

剪辑不该是把素材交给一个黑盒，再等它交回不可解释的成片。Recut 把 AI 放进真实工作流，但把决定权留在你手中：素材在哪、镜头何时出现、文字怎么排、哪一条建议该被撤销，都能在同一份项目里看见和修改。

## 从素材库到时间线

视频、图片、音频、文字和组件都进入同一个素材库。把素材拖入时间线后，它不再是一次性输入，而是项目里可随时替换、调整和复用的对象。预览、属性与多轨时间线始终并列，让每一次变化都有上下文。

## 把重复表达做成组件

品牌条、标题卡、信息图和字幕样式不需要每次重做。你可以把它们做成可复用组件，修改颜色、文字和布局等参数；完成校验后再放入成片。可复用不意味着失去控制——组件仍是你的项目资产。

## 用 Codex 或 Claude Code 驱动剪辑

向 Codex 或 Claude Code 描述创作意图，让 Agent 帮你整理素材、建立初版节奏或提出镜头建议。它的工作不是替代时间线，而是把建议放在能被审阅的位置：你可以保留、编辑、撤销，或者沿着自己的判断继续剪。

## 本地优先，开放扩展

媒体、工程和组件都由你掌握在本机。Recut 是开源、可扩展的工作台：需要新的模型、素材工作流或创作工具时，可以接入 App，而不是被固定在单一软件的边界里。
