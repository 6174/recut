本地语音转写（ASR）近年进步飞快，Qwen3-ASR 就是其中表现亮眼的开源模型：中文识别准确、带时间戳，非常适合把口播、访谈与课程视频变成字幕和文稿。它唯一的门槛在部署。

## 自部署 Qwen ASR 要准备什么

一个典型的自部署流程大概是：创建 Python 环境并安装 torch 与相关依赖，下载模型权重（Qwen3-ASR 0.6B 连同时间戳对齐器约 3.5 GB），再为转写准备 FFmpeg 与必要的音频处理链路；想要更快的速度，还要配置 CUDA 显卡。每一步都要在命令行里反复排错。

## Recut 声音工坊：把转写做成日常工具

Recut 的「声音工坊」App 用同一套 Qwen ASR 能力，但把环境问题全部封装：安装即自动准备 Python 与 FFmpeg，首次使用按需下载模型，之后离线可用。你把音视频拖进工作台，本地转写自动生成带时间戳的字幕与可编辑文稿，全程不需要打开终端。

## 转写结果怎么用

- 字幕：导出 SRT 或 ASS，直接载入剪映、PR 使用。

- 文稿：导出 Markdown，用于写稿、做讲义或发内容平台。

- 二次创作：结合 AI 配音与文稿剪辑，把「转写—校对—配音—剪辑」串成完整本地流程。

## 设备要求

基础转写建议至少 16 GB 内存；配有 NVIDIA CUDA 8 GB 以上显存可明显提速，纯 CPU 与 Apple 芯片 Mac 也能运行，只是更慢。

## 为什么值得本地转写

素材不上传、断网可用、不再被云端转写的次数与收费限制——对经常处理长访谈或涉密内容的人来说，本地转写不只是省钱，更是把控制权拿回自己手里。想体验，安装 Recut 与声音工坊，从第一条字幕开始。
