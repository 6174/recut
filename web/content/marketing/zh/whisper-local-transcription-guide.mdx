Whisper 是 OpenAI 开源的语音识别模型，也是「本地语音转写」这个搜索词背后最常见的答案：免费、离线、识别效果好。但对非开发者来说，从 pip install 到真正跑出一条字幕，中间隔着不少环境问题。

## 自己跑 Whisper 要经历什么

典型路径是：安装 Python 与 pip，创建虚拟环境，安装 openai-whisper 与依赖（包括 PyTorch），首次使用下载模型权重，再用命令行把视频转成文字。Windows 上还要处理 ffmpeg 路径；想要更快还要配置 GPU。对只想「把视频变成字幕」的人来说，这套流程的学习成本远高于收益。

## Recut 声音工坊：免配置的本地转写

Recut 的「声音工坊」App 用本地 ASR 模型（Qwen 等）提供同一类能力，但把环境问题全部封装：安装即自动准备 Python 与 FFmpeg，模型按需下载、之后离线可用。你把口播、访谈或课程视频拖进工作台，自动得到带时间戳的字幕与可编辑文稿，全程不碰命令行。

## 转写结果的三种用法

- 导出 SRT / ASS 字幕，直接载入剪映、PR。

- 导出 Markdown 文稿，用于写稿、讲义与内容平台。

- 结合 AI 配音与文稿剪辑，把「转写—校对—配音—剪辑」串成本地成片流程。

## 设备要求

基础转写建议至少 16 GB 内存；NVIDIA CUDA 8 GB 以上显存可明显提速，纯 CPU 与 Apple 芯片 Mac 也能运行，只是更慢。

## 结论

如果你需要的是本地、离线、免费的视频转字幕，不必从命令行开始。安装 Recut 与声音工坊，把第一条字幕跑出来，剩下的交给工具。
