在做视频口播、播客或短视频解说时，「AI 配音」几乎是绕不开的一环。市面上的 AI 配音软件多到挑花眼：有按字符计费的云端 API，有按月订阅的在线平台，也有完全跑在你自己电脑上的本地模型。这篇选型指南不谈玄学，只讲两件事：第一，主流云端 AI 配音工具到底怎么收费，把文字和音色样本交给它之后意味着什么；第二，如果你想要一个能长期复用、素材不出电脑的「本地声音角色」，有哪些真实可用的方案。文章中的价格都标注来源，拿不到官方数字的地方一律标注「未核实」。

## 痛点：真实的计费与上传限制

先看最影响预算的部分。MiniMax 配音（MiniMax Audio）提供两套计费：一是「音频订阅」，Starter 每月 5 美元含 10 万音频点数，Standard 30 美元 / 30 万，Pro 99 美元 / 110 万，Scale 249 美元 / 330 万，Business 999 美元 / 2000 万（来源：platform.minimax.io 官方定价页）；二是按量付费，T2A 的 speech-2.8-turbo 约 60 美元 / 百万字符，speech-2.8-hd 约 100 美元 / 百万字符，快速声音克隆 1.5 美元 / 个声音，声音设计 3 美元 / 个（来源：同官方定价页）。它支持 API 接入，WebSocket 单次最多 1 万字符、异步长文本单次最多 100 万字符；做声音克隆需要先把 mp3 / m4a / wav（10 秒到 5 分钟、20MB 以内）上传到云端，克隆出的声音若 7 天未使用会被系统删除（来源：platform.minimax.io 语音克隆文档）。

ElevenLabs 按「信用点数」计费：Free 免费档每月 1 万点数（约 10 分钟音频），Starter 6 美元 / 30 万点数，Creator 22 美元 / 121 万点数（首月 11 美元），Pro 99 美元 / 600 万，Scale 299 美元 / 180 万点数（3 席位）（来源：elevenlabs.io/pricing）。Multilingual v2 模型约 1 字符 = 1 点数，Flash / Turbo 约 0.5–1 点数 / 字符；官方语言列表明确包含中文（Chinese / Mandarin Chinese）。国内常见的讯飞配音（讯飞智作）按会员套餐售卖，包含超拟人 TTS、数字人视频与声音定制，具体价格在会员中心页面（未核实）；剪映的文本朗读、音色克隆也是会员制，具体会员价未核实。两者的共同点是：文本和音色样本要上传到云端、要联网、按月续费，且断网不可用——这是选型前必须接受的现实。

## 本地方案：CosyVoice、IndexTTS2 与 GPT-SoVITS

如果不能接受素材上传，本地开源 TTS 是另一条路。阿里 FunAudioLLM 开源的 CosyVoice（GitHub 22.8k stars，Apache-2.0）是目前中文社区最主流的本地配音模型：CosyVoice2-0.5B 参数量 0.5B，支持零样本声音克隆——只需一段几秒到几十秒的参考音频，就能让指定文本以该音色念出，并支持流式输出。官方仓库要求 Python 3.10 + conda 环境、从 ModelScope / HuggingFace 下载权重，自带 WebUI 和 Docker 部署脚本（来源：github.com/FunAudioLLM/CosyVoice）。官方没有给出明确的显存数值（未核实），0.5B 规模在消费级 GPU 上即可运行，纯 CPU 能跑但很慢。

哔哩哔哩开源的 IndexTTS2（最新 IndexTTS-2.5，0.8B 参数）主打情感与语速控制、拼音 / CMU 音素纠音，支持中英日西阿五种语言，用 uv 管理依赖，官方标注在 4090 上 RTF 约 0.2，需要 CUDA 12.8，模型需联网下载（来源：github.com/index-tts/index-tts）。RVC-Boss 的 GPT-SoVITS（60.9k stars，MIT）走 few-shot 路线：5 秒参考音色即可零样本合成，用约 1 分钟数据微调可显著提升相似度，支持中英日韩粤语，社区教程极多，Windows 有整合包，Mac 上可跑但官方注明训练质量明显打折（来源：github.com/RVC-Boss/GPT-SoVITS）。共同门槛是：Python、CUDA（或苹果芯片）、下载权重、熟悉命令行。与云端不同，这些模型的声音克隆完全在本地完成、断网可用、素材不外泄，但语音自然度与稳定性往往需要反复调参，门槛比「填文本点生成」高不少。

## 权衡：云端省心，还是本地可控？

怎么选？一句话：看你对「数据安全」和「成本结构」的敏感度。云端 AI 配音软件的优势是零门槛、音色库庞大、按量付费适合低频试用；短板是长期大量产出时订阅费用可观——按 ElevenLabs 折算，1 字符约等于 1 点数（Multilingual v2），Creator 档 12.1 万点数只够约 121 分钟音频，超出部分每分钟约 0.18 美元（来源：elevenlabs.io/pricing），对日更口播的创作者来说，一个月的配额可能几天就见底。MiniMax 按量付费下，HD 音质百万字符约 100 美元（来源：platform.minimax.io），做一本十几万字的播客稿就要上百美元。

本地方案则是一笔「用时间换月费」的买卖：前期花几小时到一天搭环境、调参数，之后合成成本几乎归零，还能给固定主播建立可复用的声音角色——这正是很多 UP 主和播客主转向本地声音克隆的真实原因。两者的声音克隆原理相近（零样本 / few-shot 学习参考音色），区别主要在于部署方式与算力归属。

## 设备要求：建一个本地声音角色需要什么

如果决定走本地路线，硬件是关键。CosyVoice 对显存不挑，官方未给明确数值（未核实），社区经验是 4GB 以上显存的 NVIDIA 显卡即可流畅推理，纯 CPU 也能用但速度感人；IndexTTS2 官方推荐 NVIDIA GPU + CUDA 12.8；GPT-SoVITS 官方在 4060 Ti 上测得 RTF 约 0.028、4090 约 0.014（v2 ProPlus），中端显卡即可接近实时合成。

不想碰命令行的话，也有现成的本地工具，比如 Recut 声音工坊就是一台「带界面」的本地模型组合：它用本地模型 Qwen3-ASR 0.6B 做转写、CosyVoice2-0.5B 做配音，全部在本机完成；支持为已授权声音建立可复用的声音角色，素材与声音不离开设备、断网可用；可导出 SRT / ASS / Markdown。基础转写建议 16GB 内存，稳定建角色/配音建议 32GB 以上内存，并预留约 15GB 磁盘空间，CUDA 加速为可选。这类工具把「本地化」的门槛从命令行降到了界面操作，适合不熟悉 Python 的内容创作者。

## 结论

回到最初的问题：AI 配音软件怎么选？低频尝鲜、不介意素材上云——直接用 ElevenLabs 免费档或 MiniMax 的订阅/按量，几美元就能跑通全流程；有固定栏目、长期需要固定音色、或对素材安全敏感——值得配置一套本地声音克隆方案，一次投入换来月费归零和「断网也能开工」。本文所有价格均来自官方定价页与官方仓库，标注「未核实」的条目请以官方最新页面为准。AI 配音工具对比没有标准答案，只有适合你成本结构的那个选择。
